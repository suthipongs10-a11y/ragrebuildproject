## 5. Review notes (written by hand)

จากการเปิดดูภาพตอนรับไฟล์และตอนตรวจ gallery — ทุกข้อรอเจ้าของโปรเจกต์ตัดสิน ยังไม่มีภาพไหนถูกแก้

### ต้องตัดสินก่อนใช้ในเกม
- **ชื่อ id ของช่องกระดานและไอคอนยังเป็นเลขลำดับชั่วคราว** (`tiles_sheet_01_0`, `icons_items_3`, …) — manifest บอกแค่ `tile_<name>` / `icon_<name>` ไม่ได้บอกชื่อ ต้องได้รายชื่อ (หรือโฟลเดอร์ `prompts/` ของชุด `03_icons`) ก่อน M2 เพราะ id เปลี่ยนไม่ได้หลังปล่อยเกม · เช่นเดียวกับ `ui_buttons_*`, `ui_panels_*`, `ui_bars_*`, `ui_tile_frames_*`, `ui_reward_cards_*`, `ui_banners_*`, และกริดเอฟเฟกต์ `fx_status_loops_*`, `fx_buff_auras_*`, `fx_projectiles_*`, `fx_particles_*`
- **ภาพแนวตั้งในเกมแนวนอน:** `ui_menu_bg`, `ui_run_map`, `keyart_portrait` เป็น 1080×1920 แต่เกมเป็น 16:9 แนวนอน → แนะนำสร้าง `ui_menu_bg` และ `ui_run_map` ใหม่เป็นแนวนอน (`prompts/25_U-title-bg.md`, `prompts/24_U-runmap.md`) · `mock_*` 4 ไฟล์เป็นแนวตั้งเช่นกัน ใช้อ้างอิงสไตล์เท่านั้น ไม่ได้แพ็ก
- **หน้าเต๋าพิเศษมี 6 หน้า** (`dice_faces_special`: ดาว, วาร์ป, ทอง, เต๋าคู่, หัวกะโหลก, มงกุฎ) แต่กติกาใน CLAUDE.md §5 มี 5 หน้า (★, วาร์ป, ทอง, x2, มงกุฎ) → หัวกะโหลกคือหน้าอะไร และเต๋าคู่ = x2 ใช่ไหม

### สไตล์
- **ชุด `03_icons`, ภาพหน้า (`portrait_*`, `leader_*_portrait`) และหมาก (`pawn_*`) ขอบนุ่ม/ไล่สี** ส่วนชุด `05_effects` และ `04_ui` เป็น pixel art คมเป็นบล็อก — ดูในแท็บ icons เทียบกับ ui แล้วตัดสินว่ารับได้หรือสร้างใหม่
- **เอฟเฟกต์วาดติดมาในท่าทาง:** ท่า attack มีเส้นฟัน/ประกาย, hurt มีดาวกระแทก, victory มีขีดดีใจ (ตัวละครทุกตัว และมอนส่วนใหญ่) — จะซ้อนกับเอฟเฟกต์ที่โค้ดเล่น (`fx_slash`, กระพริบขาว) ต้องเลือกว่าใช้ของที่วาดมาหรือของโค้ด
- **ของตกแต่งหลังแบนเนอร์บางอันหยาบ:** สี่เหลี่ยมคางหมูหลัง `LEVEL UP!`, ก้อนสีเข้มหลัง `BOSS!` (`ui_banners_1`) — ตัวสะกดถูกทั้ง 8 อัน (`prompts/22_U-banners-1.md` ถ้าจะสร้างใหม่)
