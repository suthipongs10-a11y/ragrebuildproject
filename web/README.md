# Rag Rebuild Alpha Project the Adventure Part

คู่มือและฐานข้อมูลของเซิร์ฟ (เว็บ)

เว็บ static ล้วน ไม่ต่อกับเซิร์ฟเกม แต่อ่านข้อมูลชุดเดียวกัน

## รันดูในเครื่อง

```
python3 web/serve.py
```

แล้วเปิด <http://localhost:8800>

> เปิด `index.html` ตรง ๆ ด้วย `file://` ไม่ได้ เพราะเบราว์เซอร์บล็อกทั้ง ES module และ `fetch`
> ต้องผ่าน http server เสมอ

## ใส่รูปไอเท็ม

```
python3 tools/webicons/pack.py "D:/RO/data"
```

ชี้ไปที่โฟลเดอร์ที่แตก `data.grf` ไว้ — โฟลเดอร์เดียวกับที่ตั้งใน Unity เมนู
`Ragnarok → Set Ragnarok Data Directory` (ข้างในต้องมี `texture/` กับ `sprite/`)

ได้ `web/data/icons.png` (แผ่นเดียวรวมไอคอนทุกใบ) กับ `web/data/icons.json`
เว็บหยิบไปใช้เอง ไม่ต้องแก้อะไรเพิ่ม — ตารางไอเท็ม ของที่มอนดรอป ของในร้าน NPC
รางวัลสมุดผจญภัย และสูตรคราฟ จะมีไอคอนขึ้นทั้งหมด

ไอคอนเป็นไฟล์ `.bmp` ในโฟลเดอร์ `texture/유저인터페이스/item/` ไม่ใช่ `.spr`
ตัวอ่าน bmp เขียนไว้ในสคริปต์เลย ไม่ต้องลงอะไรเพิ่ม ไม่ต้องเปิด Unity
สีพื้นหลังใช้กฎเดียวกับ `TextureImportHelper.LoadTexture` คือคีย์สีชมพู
หลัง mask ด้วย `0xF0` ไอคอนในเว็บเลยหน้าตาเหมือนในช่องไอเท็มในเกมเป๊ะ

⛔ **ไฟล์สองไฟล์นี้ gitignore ไว้ ห้าม commit** เป็นภาพของ Gravity ที่มาจาก
`data.grf` กฎเดียวกับ `Assets/Sprites/` ในข้อ 1.4 — repo นี้เป็น public
เครื่องที่มี GRF สร้างเอง เก็บไว้กับตัว ไม่ต้องส่งขึ้น git

ยังไม่มีรูปมอนสเตอร์ เพราะ sprite มอนเป็น `.spr` ต้องเขียนตัวถอดรหัสเพิ่ม

## รวมเป็นไฟล์เดียว

```
python3 web/bundle.py
```

ได้ `web/dist/guide.html` ไฟล์เดียวจบ ~2.6 MB — CSS, โมดูล JS ทุกตัว และ JSON ทั้งหมด
ฝังอยู่ข้างใน เปิดด้วย `file://` ได้ ส่งไฟล์ให้คนอื่นได้ ไม่ต้องมี server

ใช้ตอนอยากส่งคู่มือให้คนอื่นดู ส่วนตอนแก้เว็บเองยังใช้ `serve.py` เหมือนเดิม
เพราะ bundle เป็นผลลัพธ์ ไม่ใช่ต้นทาง — แก้ที่ `assets/` แล้วรัน `bundle.py` ใหม่

ตัวแปลงอ่านรูปแบบ module แค่ 4 แบบที่เว็บนี้ใช้จริง ถ้ามีไฟล์ไหนเริ่มเขียนแบบที่ 5
สคริปต์จะหยุดพร้อมบอกบรรทัด แทนที่จะปล่อยให้พังเงียบ ๆ ในเบราว์เซอร์

## อัปเดตข้อมูลหลังแก้ CSV / สคริปต์

```
python3 tools/webdata/export.py
```

สคริปต์นี้อ่านจาก `RoRebuildServer/GameConfig/ServerData/` แล้วเขียนทับ `web/data/*.json`
รันซ้ำได้ทุกครั้งที่แก้ข้อมูลเกม ไม่ต้องรัน `updateclient.bat` เพราะไม่ได้แตะ
`ServerData/`, `RebuildSharedData/` หรือ `GameConfig.Generator/`

ถ้ามีปัญหาในข้อมูล เช่นสคริปต์อ้างถึงไอเท็มที่ไม่มีอยู่ สคริปต์จะพิมพ์เตือนออกมาท้าย output

## ตรวจว่าข้อมูลตรงกับไฟล์ต้นทาง

```
python3 tools/webdata/verify.py
```

อ่านไฟล์ต้นทางใหม่แยกจาก `export.py` แล้วเทียบจำนวนแถวและค่าที่คำนวณได้
ถ้าตัวแยกข้อมูลเริ่มทำแถวหล่นจะเห็นเป็นตัวเลขที่ไม่ตรงกัน ไม่ใช่หน้าเว็บที่ดูปกติแต่ข้อมูลหายไปครึ่งหนึ่ง
คืนค่า exit code เท่ากับจำนวนจุดที่ไม่ตรง

ส่วนช่องโหว่ที่อยู่ในข้อมูลเกมเอง (อาชีพที่ HP เป็น 0, ไอเท็มที่ไม่มีอาชีพไหนใส่ได้,
แมพที่มีสคริปต์แต่ไม่ได้ลงทะเบียน) ดูได้ที่หน้า **สุขภาพข้อมูลเกม** ในเว็บ

## เอาขึ้นโฮสต์

ก๊อป `web/` ทั้งโฟลเดอร์ไปวางเป็น static site ได้เลย ไม่ต้องมี backend

> ถ้าสร้าง `icons.png` ไว้แล้ว มันจะติดไปด้วย — เป็นภาพของ Gravity
> ถ้าจะเอาขึ้นเว็บสาธารณะ ลบไฟล์นั้นออกก่อน เว็บทำงานปกติทุกอย่าง แค่ไม่มีไอคอน
ใช้ nginx, GitHub Pages, Cloudflare Pages หรืออะไรก็ได้ที่เสิร์ฟไฟล์ธรรมดา

## โครงไฟล์

```
web/
├── index.html            เปลือกหน้าเว็บ
├── serve.py              http server สำหรับดูในเครื่อง
├── bundle.py             รวมทุกอย่างเป็น dist/guide.html ไฟล์เดียว
├── assets/
│   ├── style.css         ธีมเดียวกับ ModernUiTheme.cs ในเกม
│   ├── app.js            โหลดข้อมูล, router, ค้นหา, helper สำหรับตาราง
│   ├── routes.js         ตาราง route (import หน้าแบบ lazy)
│   └── pages/*.js        หน้าแต่ละหน้า
├── data/*.json           ข้อมูลที่ export ออกมา (ห้ามแก้มือ)
├── data/icons.*          แผ่นไอคอนไอเท็ม (gitignore ไว้)
└── dist/                 ผลจาก bundle.py (gitignore ไว้)
```

## หมายเหตุเรื่องความถูกต้องของข้อมูล

- **อัตราดรอปเป็นอัตราจริง** `appsettings.json` เปิด `RemapDropRates` ไว้
  ตัวเลขใน `DropData.csv` จึงถูกแปลงก่อนใช้งาน exporter คำนวณด้วยสูตรเดียวกับ
  `Script/Config/ItemDropAndValueAdjustments.txt`
- **ราคาซื้อ/ขายเป็นราคาจริง** ผ่าน `OnSetItemPurchasePrice` / `OnSetItemSaleValue` แล้ว
- **แมพที่ไม่มีใน `Maps.csv` ไม่นับ** สคริปต์เกิดมอนของแมพพวกนั้นไม่ทำงาน
  มอนที่เกิดเฉพาะในแมพเหล่านั้นจะถูกติดป้ายว่า "ยังไม่มีที่เกิด"
- **ไอเท็มใน `MvpList.csv` ไม่ถูกโหลด** `DataLoader.LoadMvpList` อ่านแค่คอลัมน์แรก
  ไฟล์นี้จึงใช้บอกแค่ว่าตัวไหนเป็น MVP ของที่เขียนไว้ในคอลัมน์ถัด ๆ ไปไม่เคยดรอป
  เว็บจึงไม่แสดงมัน
