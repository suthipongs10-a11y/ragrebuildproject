## 0. เกมคืออะไร

ผู้เล่นเป็นผู้จัดการนักมวยหนึ่งคน วางตารางซ้อม เลือกท่าและแผนการชก แล้วส่งขึ้นเวที

**จุดขายอันดับหนึ่งคือฉากชก** ต้องสนุก เร้าใจ หลากหลายท่า และสะใจ ระบบอื่นมีไว้เพื่อให้อยากดูไฟต์ถัดไป

ไม่ทำ: บังคับหมัดเอง • ชกเรียลไทม์ระหว่างผู้เล่น • การพนัน • นักมวยหรือค่ายที่มีอยู่จริง

## 2. ⛔ กติกาที่ห้ามละเมิด

1. **ตัวจำลองแยกจากภาพ** `packages/sim` ห้ามมีโค้ดภาพ เสียง DOM หรือ canvas
2. **ผลต้องเหมือนเดิมทุกครั้งเมื่อข้อมูลเข้าเดิม** ใช้ตัวสุ่มแบบมีค่าตั้งต้นเท่านั้น
   ห้าม `Math.random()` ห้าม `Date.now()` ห้ามขึ้นกับอัตราเฟรมใน `packages/sim`
3. **ตัวเล่นภาพห้ามตัดสินผลใด ๆ เอง** อ่านจากรายการเหตุการณ์อย่างเดียว
4. **ค่าสมดุลทุกตัวอยู่ใน `packages/data`** ไม่ฝังในโค้ด
5. **แก้ตัวจำลองหรือค่าสมดุลเมื่อไร ต้องรันจำลองอย่างน้อย 2,000 ไฟต์** แล้วเทียบกับเป้าในข้อ 4
6. **ห้ามข้าม milestone** ตอนนี้ทำ P0 (ต้นแบบฉากชก 3D ใน `prototypes/fight3d/`) ตามที่เจ้าของเกมสั่ง ยังไม่เริ่ม M0 จนกว่าเจ้าของเกมจะตัดสินใจจากต้นแบบ
7. ข้อความทุกจุดผ่านระบบหลายภาษา เริ่มด้วยไทยและอังกฤษ

## 3. โครงโปรเจกต์ (เป้าหมาย)

```
muay-manager/
├── docs/
├── packages/
│   ├── sim/         ตัวจำลองล้วน + ชุดทดสอบ
│   ├── data/        ท่า สาย ค่าสมดุล เป็นไฟล์ข้อมูล
│   └── presenter/   ตัวเล่นภาพ กล้อง เอฟเฟกต์ เสียง (M0 = 2D canvas)
├── apps/
│   ├── client/      หน้าจอเกม
│   └── server/      (M3)
└── tools/balance/   สคริปต์จำลองจำนวนมากและรายงานผล
```

เครื่องมือ: TypeScript ทั้งโปรเจกต์ • npm workspaces • Vite • Vitest
3D (M1) ใช้ three.js + GLB และห่อด้วย Capacitor ยังไม่ยืนยัน ดูคำถามเปิดใน `STATUS.md`

## 4. เป้าสมดุล (นักมวยค่าพลังใกล้กัน)

| ผล | เป้า |
|---|---|
| จบยก 1 | ราว 15% |
| จบยก 2 | ราว 25% |
| จบยก 3 | ราว 25% |
