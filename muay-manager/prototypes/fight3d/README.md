# fight3d — ต้นแบบฉากชก 3D (three.js)

ต้นแบบสำหรับตอบคำถามเดียว: ฉากชกแบบไหนที่คนดูมวยดูแล้วสนุกและสะใจ
ไฟต์เดียวกัน (ค่าตั้งต้นเดียวกัน ผลเดียวกัน) เปิดดูได้หลายแบบการนำเสนอ เพื่อเทียบกันตรง ๆ

ตัวนักมวยเป็นหุ่นที่สร้างจากรูปทรงพื้นฐาน ยังไม่ใช่โมเดลจริง เสียงเป็นเสียงสังเคราะห์ชั่วคราว

## รัน

```bash
npm install
npm run build        # ได้ dist/muay-fight-lab.html (ไฟล์เดียว เปิดในเบราว์เซอร์ได้เลย)
npm test             # ยืนยันว่าค่าตั้งต้นเดิมให้ไฟต์เดิมทุกครั้ง
npm run batch        # จำลอง 2,000 ไฟต์ รายงานเทียบเป้าสมดุล
```

หน้าเว็บโหลด three.js 0.160.0 จาก cdnjs ต้องต่ออินเทอร์เน็ตตอนเปิด

## โครง

| ไฟล์ | หน้าที่ |
|---|---|
| `src/data.js` | ท่า 12 ท่า ท่าไม้ตาย 5 ท่า ชุดต่อเนื่อง 10 ชุด สาย 4 แบบ และค่าสมดุลทั้งหมด |
| `src/sim.js` | ตัวจำลองล้วน ใช้ตัวสุ่มมีค่าตั้งต้น ออกรายการเหตุการณ์ + สถานะรายจังหวะ + คิวท่า |
| `src/timeline.js` | แปลงผลจำลองเป็นท่าทางรายจังหวะที่กรอไปมาได้ เล็งอาวุธเข้าเป้า และให้ผู้รับเริ่มบังก่อนโดน |
| `src/poses.js` | คลังท่า 3D 47 ท่า |
| `src/rig.js` | โครงกระดูก (IK สองท่อน) และตัวหุ่น |
| `src/arena.js` `src/fx.js` `src/audio.js` | เวที คนดู แสง / ประกาย เส้นความเร็ว / เสียงสังเคราะห์ |
| `src/main.js` | ตัวเล่นภาพ ผู้กำกับกล้อง สโลว์ ภาพช้าหมัดน็อก และตัวเลือกการนำเสนอ |
| `tools/` | จำลองจำนวนมาก ทดสอบผลซ้ำ หาไฟต์ตัวอย่าง |

`sim.js` และ `data.js` ไม่มีโค้ดภาพ ย้ายเข้า `packages/sim` และ `packages/data` ได้ตรง ๆ เมื่อเริ่ม M0

## แบบการนำเสนอ 4 แบบ

| แบบ | กล้อง | ตัวนักมวย | จังหวะ |
|---|---|---|---|
| ถ่ายทอดสด | ด้านข้าง นิ่ง | สมจริง | เอฟเฟกต์น้อย สโลว์เฉพาะตอนน็อก |
| ภาพยนตร์ | ผู้กำกับ ตัดมุมตอนท่าไม้ตายและตอนล้ม | สมจริง แสงจัด | สโลว์หมัดใหญ่ มีป้ายชื่อท่าใหญ่ |
| อาร์เคด | ด้านข้าง ซูมตามหมัด | การ์ตูนตัดเส้น | หยุดภาพและจอสั่นแรง ป้ายทุกจังหวะ ตัวนับชุด |
| ข้างเวที | มุมต่ำ กล้องถือมือ มองผ่านเชือก | สมจริง | เอฟเฟกต์น้อย ไม่มีภาพช้า |

ทุกตัวเลือกปรับแยกได้ใน "ปรับทีละอย่าง" เพื่อผสมแบบที่ชอบ

## ยังไม่มีในต้นแบบนี้

การกอดปล้ำ • ติดเชือกและติดมุม • แผนการชกของผู้เล่น • ท่าพื้นฐานอีก 4 ท่าและแม่ไม้อีก 7 ท่าจาก `FIGHT_DESIGN.md` • เสียงจริง • โมเดลและท่าจากนักแอนิเมชัน

## ยังไม่ได้ตรวจ

- ความลื่นบนมือถือจริง (ตรวจได้แค่ในเบราว์เซอร์จำลองที่ไม่มีการ์ดจอ) มุมขวาล่างของฉากแสดง fps ให้ดูบนเครื่องจริง
- เสียง ยังไม่มีใครฟัง
