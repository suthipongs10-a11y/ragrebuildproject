# fight3d — ต้นแบบฉากชก 3D (three.js)

ต้นแบบสำหรับตอบคำถามเดียว: ฉากชกแบบไหนที่คนดูมวยดูแล้วสนุกและสะใจ
ไฟต์เดียวกัน (ค่าตั้งต้นเดียวกัน ผลเดียวกัน) เปิดดูได้หลายแบบการนำเสนอ เพื่อเทียบกันตรง ๆ

ตัวนักมวยเป็นโมเดล 3D ที่สร้างด้วย Meshy (ภาพอ้างอิง → โมเดลมีผิว → ใส่กระดูกอัตโนมัติ) แล้วขยับด้วยท่าชุดเดียวกับตัวที่สร้างจากโค้ด ซึ่งยังเลือกกลับไปใช้ได้ เสียงเป็นเสียงสังเคราะห์ชั่วคราว

## รอบที่ 3: โมเดลนักมวยจริง (10 พ.ย. 2026)

- `assets/fighter-a.glb` มุมแดง ตัวถึก และ `assets/fighter-b.glb` มุมน้ำเงิน ตัวเพรียว พร้อมภาพอ้างอิงคู่กัน
- `src/model.js` โหลดโมเดลและเขียนเมทริกซ์ของกระดูกทุกชิ้นจากข้อต่อที่ตัวแก้ท่าคำนวณ ไม่ใช้คลิปแอนิเมชัน
- สองตัวใช้โครงกระดูกร่วมขนาดกลางระหว่างสองโมเดล แขนขายืดหดเล็กน้อยให้ลงข้อต่อ ท่าทั้งชุดปรับความสูงตามสัดส่วนโมเดลอัตโนมัติ
- ถ้าโหลดโมเดลไม่ได้ จะใช้ตัวที่สร้างจากโค้ดแทนเอง
- สร้างนักมวยเพิ่ม: `node tools/meshy-fighter.mjs <ชื่อ> "<คำบรรยาย>"` ต้องมี API key ของ Meshy (แผนเสียเงิน) ใช้ 44 เครดิตต่อตัว (ภาพ 9 + โมเดล 30 + กระดูก 5)

ข้อจำกัดที่เห็นแล้ว
- เชือกประเจียดที่ห้อยจากต้นแขนถูกผูกน้ำหนักกับลำตัว จึงยืดเป็นเส้นเมื่อยกแขน
- ไหล่และสะโพกบิดตามมุมยกแขนขาแบบตรง ๆ ยังไม่มีการแก้ผิวตรงข้อต่อ
- ผิวตัวนักมวยเปลี่ยนสีตามความบอบช้ำได้ทั้งตัวเท่านั้น ไม่แยกหัว ลำตัว ขา

## รอบที่ 2 (ตามความเห็นเจ้าของเกม 10 พ.ย. 2026)

- กล้อง "ถ่ายทอดสด" ตัดสลับ 5 กล้องแบบรายการมวย (กล้องหลัก กล้องแน่น มุมสูง ข้างเวที ภาพหน้านักมวย) ใช้เลนส์ซูมจากตำแหน่งคงที่ มีภาพช้าช่วงพักยกและตอนน็อก เป็นค่าเริ่มต้น
- ตัวนักมวยใหม่ ตัวหนาและมีกล้าม เลือกรูปร่างได้ 3 แบบ (ถึก สมส่วน เพรียว) หรือให้ตามสายมวย
- นักมวยตั้งการ์ดรับเมื่ออ่านอาวุธออก (อ่านผิดระดับได้) และยืนจังหวะแบบมวยไทย
- เพิ่มถีบหน้า แยกจากถีบท้อง และชุด "ถีบท้องถีบหน้า"
- คะแนนสดข้างชื่อนักมวย และป้ายคะแนนหลังจบยก

## รัน

```bash
npm install
npm run build        # ได้ dist/muay-fight-lab.html (ไฟล์เดียว เปิดในเบราว์เซอร์ได้เลย)
npm test             # ยืนยันว่าค่าตั้งต้นเดิมให้ไฟต์เดิมทุกครั้ง
npm run batch        # จำลอง 2,000 ไฟต์ รายงานเทียบเป้าสมดุล
```

หน้าเว็บโหลด three.js 0.160.0 จาก cdnjs ต้องต่ออินเทอร์เน็ตตอนเปิด และต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เช่น `npx serve dist`) เพื่อให้โหลดไฟล์โมเดลใน `dist/` ได้

## โครง

| ไฟล์ | หน้าที่ |
|---|---|
| `src/data.js` | ท่า 13 ท่า ท่าไม้ตาย 5 ท่า ชุดต่อเนื่อง 11 ชุด สาย 4 แบบ และค่าสมดุลทั้งหมด |
| `src/sim.js` | ตัวจำลองล้วน ใช้ตัวสุ่มมีค่าตั้งต้น ออกรายการเหตุการณ์ + สถานะรายจังหวะ + คิวท่า |
| `src/timeline.js` | แปลงผลจำลองเป็นท่าทางรายจังหวะที่กรอไปมาได้ เล็งอาวุธเข้าเป้า และให้ผู้รับเริ่มบังก่อนโดน |
| `src/poses.js` | คลังท่า 3D 49 ท่า |
| `src/rig.js` | โครงกระดูก (IK สองท่อน) และตัวนักมวยแบบสร้างจากโค้ด |
| `src/model.js` | ตัวนักมวยจากโมเดล 3D ที่มีกระดูก |
| `src/arena.js` `src/fx.js` `src/audio.js` | เวที คนดู แสง / ประกาย เส้นความเร็ว / เสียงสังเคราะห์ |
| `src/main.js` | ตัวเล่นภาพ ผู้กำกับกล้อง สโลว์ ภาพช้าหมัดน็อก และตัวเลือกการนำเสนอ |
| `tools/` | จำลองจำนวนมาก ทดสอบผลซ้ำ หาไฟต์ตัวอย่าง |

`sim.js` และ `data.js` ไม่มีโค้ดภาพ ย้ายเข้า `packages/sim` และ `packages/data` ได้ตรง ๆ เมื่อเริ่ม M0

## แบบการนำเสนอ 4 แบบ

| แบบ | กล้อง | จังหวะ |
|---|---|---|
| ถ่ายทอดสด (ค่าเริ่มต้น) | ตัดสลับ 5 กล้อง เลนส์ซูม | สโลว์เฉพาะตอนน็อก ภาพช้าช่วงพักยกและตอนน็อก |
| ภาพยนตร์ | ผู้กำกับ ตัดมุมตอนท่าไม้ตายและตอนล้ม แสงจัด | สโลว์หมัดใหญ่ |
| ข้างเวที | มุมต่ำ กล้องถือมือ มองผ่านเชือก | เอฟเฟกต์น้อย ไม่มีภาพช้า |
| อาร์เคด | ด้านข้าง ซูมตามหมัด ตัวการ์ตูนตัดเส้น | หยุดภาพและจอสั่นแรง ป้ายทุกจังหวะ |

ทุกตัวเลือกปรับแยกได้ใน "ปรับทีละอย่าง" รวมถึงรูปร่างนักมวย

## ยังไม่มีในต้นแบบนี้
