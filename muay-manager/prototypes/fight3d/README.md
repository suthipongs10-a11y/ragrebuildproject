# fight3d — ต้นแบบฉากชก 3D (three.js)

ต้นแบบสำหรับตอบคำถามเดียว: ฉากชกแบบไหนที่คนดูมวยดูแล้วสนุกและสะใจ
ไฟต์เดียวกัน (ค่าตั้งต้นเดียวกัน ผลเดียวกัน) เปิดดูได้หลายแบบการนำเสนอ เพื่อเทียบกันตรง ๆ

ตัวนักมวยเป็นโมเดล 3D ที่สร้างด้วย Meshy (ภาพอ้างอิง → โมเดลมีผิว → ใส่กระดูกอัตโนมัติ) แล้วขยับด้วยท่าชุดเดียวกับตัวที่สร้างจากโค้ด ซึ่งยังเลือกกลับไปใช้ได้ เสียงเป็นเสียงสังเคราะห์ชั่วคราว

## รอบที่ 10: สามท่าที ตั้งรับ เดินตี ดูเชิง (11 พ.ย. 2026)

แผน "ท่าที" ของแต่ละยกกำหนดทั้งวิธีชกและท่าทางระหว่างจังหวะ ชื่อในเกมเปลี่ยนเป็น **ตั้งรับ • เดินตี • ดูเชิง** (เดิม ตั้งรับสวนกลับ • บุก • สมดุล)

| ท่าที | ตัวจำลอง (`PLAN_RULES` ใน `data.js`) | ท่าทาง (`src/timeline.js`) |
|---|---|---|
| ตั้งรับ | แทบไม่เดินเข้าหา (ความเร็วเดินหน้า ×0.22 และ ×0.75 เมื่อเลือกอาวุธแล้ว) ถีบบ่อยขึ้น ×1.9 ถีบดันไกลขึ้น ×1.3 | ไม่เด้ง เท้าปักพื้น ตัวย่อลงยกขึ้นช้า ๆ โยกซ้ายขวาและหน้าหลัง การ์ดยื่นยาว สลับเท้าช้า ๆ ทีละก้าวเป็นครั้งคราว |
| เดินตี | เดินหน้าเร็วขึ้น ×1.12 เข้ากอดบ่อยขึ้น ×1.25 | ไม่เด้ง ก้าวเดิน คางเก็บหลังการ์ดสูง ไหล่โยกตามก้าว ไม่โยกก้มเอง |
| ดูเชิง | ค่ากลาง | เด้งเบา ๆ ราว 2.3 วินาที แล้วหยุดยืนโยกซ้ายขวา 1 วินาที สลับกันไป มีกระโดดสลับเท้า |

- **ถีบกระเด็นล้ม:** ลูกถีบที่เข้าเป้ามีโอกาสทำให้คู่ชกล้มก้นจ้ำเบ้า ไม่นับ ได้คะแนนเท่าเหวี่ยงล้ม โอกาสพื้นฐาน 3% ฝ่ายตั้งรับ +5% คู่ชกเดินตี +4% ถีบสวนตอนเขาออกอาวุธ +8% คู่ชกแรงใกล้หมด +6%
- **ยกเข่าบังเตะ:** เตะลำตัวที่ถูกบังแสดงเป็นท่ายกเข่าขึ้นรับ ศอกกดลง (ท่าใหม่ `checkBody`)
- ตัวจำลองส่งเหตุการณ์ `plan` ตอนต้นยก ตัวเล่นภาพอ่านท่าทีจากตรงนั้น
- หน้าทดลองเลือกท่าทีของแต่ละมุมได้ใน "ปรับทีละอย่าง" ค่าเริ่มต้น มุมแดงเดินตี มุมน้ำเงินตั้งรับ
- กติกา proto-0.6 ผล 2,000 ไฟต์ (ดูเชิงทั้งคู่): ยก 1 11.8% • ยก 2 24.4% • ยก 3 22.6% • คะแนน 41.3% • ล้ม 1.26 • ค่าพลังสูงกว่า 10% ชนะ 64.0%
- ผลของท่าทีต่ออัตราชนะ (ค่าพลังเท่ากัน 240 ไฟต์ต่อช่อง): เดินตี −20 ถึง +4 จุด • ตั้งรับ −8 ถึง +6 จุด แล้วแต่คู่สาย ยังไม่ได้สร้าง `src/plantips.js` ใหม่

**คะแนนตอนถูกนับ (ข้อมูลที่ค้นมา ยังไม่ได้ใส่ในเกม):** มวยไทยใช้ระบบ 10 คะแนนต่อยก ผู้ชนะยกได้ 10 ผู้แพ้ได้ 9 ถ้าถูกนับหนึ่งครั้งในยกนั้นเป็น 10:8 ถูกนับสองครั้งเป็น 10:7 (กติกาสภามวยไทยโลก) รายละเอียดต่างกันตามผู้จัด ต้นแบบนี้ใช้คะแนนสะสมจากความเสียหาย บวก 15 ต่อการทำล้มหนึ่งครั้ง

## รอบที่ 9: เคลื่อนที่ด้วยการเด้ง แทนการก้าวเดิน (11 พ.ย. 2026)

- ตอนคุมเชิง นักมวย**เคลื่อนที่ด้วยการเด้ง**: เท้าปักพื้นตอนลง แล้วเท้าทั้งสองย้ายพร้อมกันตอนตัวลอย ไปยังจุดที่ต้องยืนตอนลงพื้น (`footwork` ใน `src/timeline.js`) การก้าวทีละข้างเหลือเฉพาะตอนไม่ได้เด้ง (กำลังออกอาวุธ โดนอาวุธ) หรือเท้าตามไม่ทันเกิน 24 ซม.
- จังหวะเด้งราว 2.1 ครั้งต่อวินาที และ**ถี่ขึ้นเมื่อเคลื่อนที่เร็ว** (สูงสุด 1.9 เท่า) เพื่อให้แต่ละจังหวะย้ายเท้าไม่เกินราว 30 ซม. ตัวลอย 3.2 ซม.
- **สลับเท้า** ราว 15% ของจังหวะเด้ง เท้านำถอย 30 ซม. เท้าหลังขึ้น 30 ซม. หนึ่งจังหวะแล้วกลับ
- โยกก้มเองถี่ขึ้นเล็กน้อย (ทุก 2 วินาที โอกาส 80%)
- เป็นงานของตัวเล่นภาพล้วน ผลการชกไม่เปลี่ยน

## รอบที่ 8: เด้งตัว โยกหลบ ก้มหลบหมัด (11 พ.ย. 2026)

- **เด้งตัวเบา ๆ ตอนยืนคุมเชิง** (`sample` ใน `src/timeline.js`): ตัวลอยขึ้น 2.6 ซม. ราว 1.5 ครั้งต่อวินาที เข่ายุบตอนลง น้ำหนักโยกหน้าหลัง เท้านำแตะพื้น นักมวยที่แรงเหลือน้อยกว่า 25% เด้งเหลือไม่ถึงครึ่ง ค่อย ๆ เข้าออกรอบท่าอื่นด้วยค่า `idleW`
- **โยกก้มหลบเอง** ทุก 2.4 วินาทีมีโอกาส 72% ที่หัวจะก้มลงแล้วโยกจากข้างหนึ่งไปอีกข้าง ใช้เวลา 0.7 วินาที
- **ท่าหลบตามอาวุธที่มา** (ท่าใหม่ `duck` `slipL` `slipR` ใน `src/poses.js`): ก้มลอดฮุก ศอก ก้านคอ และหมัดตรงครึ่งหนึ่ง • เอี้ยวหลบแย็บและหมัดตรง • ที่เหลือเอนหลังแบบเดิม ตัวเล่นภาพเลือกท่าเอง ตัวจำลองบอกแค่ว่าหลบได้
- **ตัวจำลองเปลี่ยน (proto-0.5):** `evadeShare: .6` ใน `data.js` การ์ดที่กันอาวุธระดับหัวได้ ส่วนหนึ่งกลายเป็นการหลบ (คูณด้วยความเร็ว / 55) เดิมหลบได้ 1.1 ครั้งต่อไฟต์ซึ่งน้อยจนแทบไม่เห็น ตอนนี้ 6.0 ครั้ง บัง 12.5 ครั้ง (เดิม 17.2)
- ผล 2,000 ไฟต์หลังเปลี่ยน: ยก 1 12.2% • ยก 2 25.1% • ยก 3 22.4% • คะแนน 40.3% • ล้ม 1.30 ต่อไฟต์ • ฝั่งค่าพลังสูงกว่า 10% ชนะ 65.9% ใกล้เคียงก่อนเปลี่ยน
- ยังไม่ได้สร้างตารางคำแนะนำแผน (`src/plantips.js`) ใหม่หลังเปลี่ยนกติกานี้

## รอบที่ 7: แก้ตัวนักมวย ผู้ชม และฟุตเวิร์ก (11 พ.ย. 2026)

- **ตัว `a` (ตัวถึก กางเกงลายทอง) สร้างใหม่** ตัวเดิมถูกสร้างตอนแรกด้วยการจัดท่าของ Meshy ทำให้แขนแนบลำตัว ผิวใต้รักแร้ติดกับลำตัวและพู่ประเจียดห้อยในร่อง พอยกแขนจึงยืดเป็นแผ่นคล้ายปีก ลองตัดด้วยโค้ดแล้วขอบแหว่ง จึงสร้างใหม่จากภาพต้นแบบเดิม (ลบพู่ออกจากภาพ) โดยไม่จัดท่า ใช้ 35 เครดิต หน้าตาเดิม
- **ผู้ชมไม่โยกตลอดเวลาแล้ว** ยืนหรือนั่งนิ่ง เมื่อไฟต์เดือด (ค่า hype เกินเกณฑ์ของแต่ละคน) จึงลุกขึ้นและชูแขน ยิ่งเดือดยิ่งลุกมาก แล้วค่อยนั่งลง ตัวที่ไม่ขยับไม่ถูกคำนวณใหม่
- **ฟุตเวิร์ก** (`footwork` ใน `src/timeline.js`): เท้าปักอยู่กับพื้นเวที เมื่อตัวเคลื่อนไปเกิน 8 ซม. เท้าจึงก้าวตามทีละข้าง เดินหน้าเท้านำก้าวก่อน ถอยหลังเท้าหลังก้าวก่อน ยกเท้า 5 ซม. ก้าวละ 0.10–0.16 วินาที ทำเฉพาะตอนเท้าอยู่บนพื้นและไม่ได้หมุนตัวหรือกระโดด เป็นงานของตัวเล่นภาพล้วน ผลการชกไม่เปลี่ยน
- แก้: หน้าเมนูขึ้นนักมวยซ้อนสองตัวเมื่อเรียกแสดงตัวซ้อนกัน

## รอบที่ 6: เวทีหลายแบบ มวยคาดเชือก และการซ้อมแบบกดเอง (11 พ.ย. 2026)

เวที (`src/arena.js`) สร้างจากโค้ดทั้งหมด สร้างเมื่อถูกเรียกครั้งแรกแล้วเก็บไว้ แสดงทีละเวที
| รหัส | เวที | ใช้ที่ไหนในเกม |
|---|---|---|
| `temple` | เวทีมวยวัด กลางแจ้งตอนกลางคืน ไฟประดับ ธงราว ร้านค้า ชิงช้าสวรรค์ โบสถ์ คนดูยืน | ท้าชกงานวัด และศึกจัดอันดับระดับงานวัดกับอำเภอ |
| `province` | เวทีจังหวัด โรงมวยหลังคาสังกะสี ไฟนีออน ป้ายเขียนมือ อัฒจันทร์ 4 แถว | ศึกจัดอันดับระดับจังหวัด |
| `stadium` | เวทีมาตรฐาน (เวทีเดิม) | ศึกจัดอันดับระดับมาตรฐาน |
| `champ` | เวทีใหญ่ชิงแชมป์ อัฒจันทร์ 12 แถว ดำทอง จอใหญ่ ไฟกวาด | ศึกชิงแชมป์ |
| `chuek` | ลานมวยคาดเชือก ลานดิน เชือกปอ คบเพลิง กำแพงเมือง พลับพลา ยามเย็น | ศึกมวยคาดเชือก วันละ 1 ไฟต์ |
| `camp` | ค่ายมวย โรงซ้อมหลังคาสังกะสี กลางวัน | หน้าเมนูและการซ้อม |

- แบบการนำเสนอ (ถ่ายทอดสด ภาพยนตร์ ข้างเวที อาร์เคด) เป็นตัวคูณบนแสงของแต่ละเวที ใช้ร่วมกันได้ทุกเวที หน้าทดลองเลือกเวทีได้ใน "ปรับทีละอย่าง"
- **มวยคาดเชือก:** นวมกลายเป็นหมัดพันเชือก (ลายเชือกวาดบนผิวเดิม หมัดย่อลง 20%) กติกาต่างจากเวทีปกติที่ `VENUE_RULES.chuek` ใน `data.js`: ความเสียหาย ×1.12 และการ์ดกันได้น้อยลง ตัวจำลองรับ `opts.rules` ต่อไฟต์ ผล 2,000 ไฟต์: ตัดสินคะแนนเหลือ 29.8% (เวทีปกติ 39.9%)
- **ซ้อมแบบกดเอง** (`src/drill.js`): นักมวยยืนหน้าเป้า 3 แบบ กระสอบทราย ต้นกล้วย หุ่นซ้อม ครูเรียกท่า ต่อย เตะ ถีบ เป็นป้ายเลื่อนเข้าวงกลม ผู้เล่นกดให้ตรงจังหวะ นักมวยออกท่าจริงใส่เป้า เป้าแกว่ง สั่น ตามแรง
  - ตัวตัดสินจังหวะและการให้ค่าพลังอยู่ใน `src/game.js` (`DRILL`, `DRILL_MIX`, `KINDS`) ตัวเล่นภาพไม่ตัดสินอะไร
- ผลจำลองเวทีปกติ 2,000 ไฟต์เท่ารอบที่ 5 ทุกตัวเลข (ตัวจำลองไม่ได้เปลี่ยนพฤติกรรม)

ยังไม่ได้ทำ: เวทีอำเภอยังใช้เวทีงานวัด • กรรมการ พี่เลี้ยง ดนตรีปี่กลอง • มวยคาดเชือกยังใส่กางเกงมวยสมัยใหม่ • วิ่ง กระโดดเชือก ลงนวม ยังเป็นปุ่มจังหวะแบบเดิม

## รอบที่ 5: ระบบเกม (11 พ.ย. 2026)

ได้สองหน้าจากโค้ดชุดเดียว
- `dist/muay-fight-lab.html` หน้าทดลองฉากชกเหมือนเดิม
- `dist/muay-manager.html` **ต้นแบบเกม**: สร้างนักมวย ซ้อม แต่งตัว หาคู่ชก วางแผน ดูไฟต์และแก้แผนพักยก รับรางวัล ไต่อันดับ ออกแบบไว้ใน `docs/GAME_SYSTEM_DESIGN.md`

ฉากชก
- **โน้มคอตีเข่า:** เข่าเข้าหน้าในวงกอด ทำเมาหมัดและล้มได้ เฉลี่ย 1.4 ครั้งต่อไฟต์
- **เหวี่ยงล้ม:** จบวงกอดด้วยการเหวี่ยง ได้คะแนน ไม่นับ เฉลี่ย 0.3 ครั้งต่อไฟต์ และมีการฟัดโยกกันในวงกอด
- **แผนการชก** ต่อยก: ท่าที ระยะ เป้าเน้น (`PLAN_RULES` ใน `data.js`) และจำลองซ้ำด้วยค่าสุ่มเดิมเมื่อแก้แผนพักยก
- ท่าไม้ตายเลือกได้ต่อนักมวย (`spec.sp`)
- ปรับสมดุล: แรงฟื้นเร็วขึ้น (ท้ายยกเหลือแรงเฉลี่ย 37% จากเดิม 22%) สายหมัดหนักและเข่าศอกเดินเร็วและทนขึ้น

ไฟล์ใหม่: `src/game.js` (ระบบเกม) • `src/entry-game.js` • `src/plantips.js` (สร้างจาก `tools/plantips.mjs`) • `tools/plans.mjs` `tools/growth.mjs` `tools/finish.mjs`

การบันทึก: เก็บในเบราว์เซอร์ และเก็บในฐานข้อมูลของ artifact เมื่อเชื่อมได้ (ตารางอันดับร่วมและบันทึกส่วนตัว) หน้าเกมต้องเผยแพร่พร้อม `capabilities: {db: {rules: [...]}, user: {}}`

## รอบที่ 4: การน็อก กอดคอ จับขา และตัวนักมวยให้เลือก (10 พ.ย. 2026)

- **การน็อก:** หมัดที่เข้าจัง ๆ (สวนหรือเข้าเต็ม) เพิ่มโอกาสล้มและนับไม่ลุก ผล 2,000 ไฟต์: ปิดเกมด้วยหมัด 47% เตะก้านคอ 19% ศอก 17% ท่าไม้ตายรวม 13% (จระเข้ฟาดหาง 1%)
- **กอดคอตีเข่า:** เข้ากอดแล้วตีเข่า 2–4 ครั้ง ฝ่ายถูกกอดสะบัดหลุดได้ ไม่งั้นกรรมการแยก เฉลี่ย 1.4 ครั้งต่อไฟต์
- **จับขาแล้วชก:** รับเตะลำตัวด้วยการจับขา แล้วชกหน้าหรือลำตัวด้วยมืออีกข้าง ไม่ทำให้ล้ม เฉลี่ย 0.7 ครั้งต่อไฟต์
- **ตัวนักมวย 6 แบบ** (`assets/fighter-a` ถึง `-f`) เลือกได้ต่อมุม ตั้งชื่อเองได้
- **เครื่องแต่งกายแยกจากตัว** (`src/outfit.js`): เปลี่ยนสีกางเกง สีนวม ลายกางเกง 5 แบบ และมงคลหรือผ้าคาดหัว ได้กับทุกตัว โดยแทนสีพื้นของกางเกงและนวมในผิวโมเดล ลายคำนวณจากตำแหน่งบนตัว
- เปิดหน้าครั้งแรกจะสุ่มไฟต์ตัวอย่างที่จบต่างกัน 5 แบบ

ข้อควรรู้ตอนสร้างนักมวยเพิ่ม
- ให้ภาพอ้างอิงใส่กางเกงและนวมสีน้ำเงินล้วน ไม่มีประเจียดและผ้าหัว เพื่อให้เปลี่ยนสีได้สะอาด
- อย่าใช้ `pose_mode` ตอนแปลงภาพเป็นโมเดล เคยทำให้ 3 ใน 4 ตัวออกมาไม่มีนวม สคริปต์ `tools/meshy-fighter.mjs` ปิดไว้แล้ว และมี `--from-image` สำหรับสร้างซ้ำจากภาพเดิม

## รอบที่ 3: โมเดลนักมวยจริง (10 พ.ย. 2026)

- `assets/fighter-a.glb` มุมแดง ตัวถึก และ `assets/fighter-b.glb` มุมน้ำเงิน ตัวเพรียว พร้อมภาพอ้างอิงคู่กัน
- `src/model.js` โหลดโมเดลและเขียนเมทริกซ์ของกระดูกทุกชิ้นจากข้อต่อที่ตัวแก้ท่าคำนวณ ไม่ใช้คลิปแอนิเมชัน
- สองตัวใช้โครงกระดูกร่วมขนาดกลางระหว่างสองโมเดล แขนขายืดหดเล็กน้อยให้ลงข้อต่อ ท่าทั้งชุดปรับความสูงตามสัดส่วนโมเดลอัตโนมัติ
- ถ้าโหลดโมเดลไม่ได้ จะใช้ตัวที่สร้างจากโค้ดแทนเอง
- สร้างนักมวยเพิ่ม: `node tools/meshy-fighter.mjs <ชื่อ> "<คำบรรยาย>"` ต้องมี API key ของ Meshy (แผนเสียเงิน) ใช้ 44 เครดิตต่อตัว (ภาพ 9 + โมเดล 30 + กระดูก 5)

ข้อจำกัดที่เห็นแล้ว
- เชือกประเจียดที่ห้อยจากต้นแขนถูกผูกน้ำหนักกับลำตัว จึงยืดเป็นเส้นเมื่อยกแขน
- ไหล่และสะโพกบิดตามมุมยกแขนขาแบบตรง ๆ ยังไม่มีการแก้ผิวตรงข้อต่อ
- ผิวตัวนักมวยเปลี่ยนสีตามความบอบช้ำได้ทั้งตัวเท่านั้น ไม่แยกหัว ลำตัว ขา

## รอบที่ 2 (ตามความเห็นเจ้าของเกม 10 พ.ย. 2026)

- กล้อง "ถ่ายทอดสด" ตัดสลับ 5 กล้องแบบรายการมวย (กล้องหลัก กล้องแน่น มุมสูง ข้างเวที ภาพหน้านักมวย) ใช้เลนส์ซูมจากตำแหน่งคงที่ มีภาพช้าช่วงพักยกและตอนน็อก เป็นค่าเริ่มต้น
- ตัวนักมวยใหม่ ตัวหนาและมีกล้าม เลือกรูปร่างได้ 3 แบบ (ถึก สมส่วน เพรียว) หรือให้ตามสายมวย
- นักมวยตั้งการ์ดรับเมื่ออ่านอาวุธออก (อ่านผิดระดับได้) และยืนจังหวะแบบมวยไทย
- เพิ่มถีบหน้า แยกจากถีบท้อง และชุด "ถีบท้องถีบหน้า"
- คะแนนสดข้างชื่อนักมวย และป้ายคะแนนหลังจบยก

## รัน

```bash
npm install
npm run build        # ได้ dist/muay-fight-lab.html (ไฟล์เดียว เปิดในเบราว์เซอร์ได้เลย)
npm test             # ยืนยันว่าค่าตั้งต้นเดิมให้ไฟต์เดิมทุกครั้ง
npm run batch        # จำลอง 2,000 ไฟต์ รายงานเทียบเป้าสมดุล
```

หน้าเว็บโหลด three.js 0.160.0 จาก cdnjs ต้องต่ออินเทอร์เน็ตตอนเปิด โมเดลทั้ง 6 ตัวฝังอยู่ในไฟล์หน้าเว็บ (ราว 10.5 MB) เพราะแอปมือถือของ Claude ปฏิเสธการขอไฟล์ที่วางข้างหน้า artifact (403) ถ้าแก้ผิวโมเดล ให้รัน `python3 tools/shrink-textures.py` ก่อน build ต้องใช้เบราว์เซอร์ที่มี DecompressionStream (iOS 16.4 ขึ้นไป)
