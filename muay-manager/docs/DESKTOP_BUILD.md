# แอปบนคอมพิวเตอร์ (Windows, Linux / Steam Deck) — Muay Manager

เขียน 20 พ.ย. 2026 ที่ต้นแบบ 2.66 ทางไป Steam ข้อ 2 (ข้อ 1 คือภาษาอังกฤษ ทำแล้วในรอบที่ 92)

## 1. คืออะไร

แอปที่ห่อเกมเดียวกับเว็บด้วย Electron (Chromium ติดมากับแอป ภาพ 3D จึงเหมือนกันทุกเครื่อง ไม่ขึ้นกับเบราว์เซอร์ที่ลงไว้)

- ไฟล์เกมอยู่ในแอป (`resources/app/site` สำเนาของ `dist/site`) เปิดที่ `muay://game/` ไม่ได้โหลดหน้าเว็บจากเน็ต
- ส่วนออนไลน์ (อันดับ ท้าชก แชท ข่าว ศึกชิงถ้วย) คุยกับเซิร์ฟเวอร์เดียวกับเว็บ `https://muay.eggpact.com/api` ตามสัญญาเดียวกับแอปมือถือ (`MUAY_API` `MUAY_WEB` ใน `docs/APP_BUILD_GUIDE.md`) ผู้เล่นบนเว็บ มือถือ และคอมจึงอยู่ในตารางอันดับเดียวกัน
- เซฟอยู่ในเครื่อง: Windows `%APPDATA%\Muay Manager\` • Linux `~/.config/Muay Manager/` (และสำรองบนเซิร์ฟเวอร์เหมือนเว็บ ย้ายเครื่องด้วยรหัสย้ายเครื่องได้)
- ไม่มีโฆษณาและการซื้อ (`MuayNative` ไม่มี เกมอยู่ในโหมด `none` เหมือนเว็บ)

| ส่วน | ไฟล์ |
|---|---|
| ตัวห่อ: หน้าต่าง ไฟล์เกม ลิงก์ออกนอกเกม ปุ่มเต็มจอ จำขนาดหน้าต่าง | `prototypes/fight3d/desktop/main.cjs` |
| บอกเกมว่าเซิร์ฟเวอร์อยู่ไหน | `prototypes/fight3d/desktop/preload.cjs` |
| ไอคอน (สร้างจาก `site/icon-512.png`) | `prototypes/fight3d/desktop/icon.ico` `icon.png` |
| สร้างแอป | `prototypes/fight3d/tools/desktop-build.mjs` (`npm run desktop`) |
| ทดสอบแอปจริง | `prototypes/fight3d/tools/e2e/desktop.mjs` (`npm run e2e:desktop`) |

## 2. สร้างและทดสอบ

```bash
cd muay-manager/prototypes/fight3d
npm run desktop            # สร้างเว็บใหม่ แล้วสร้างแอป Windows และ Linux (--no-build ใช้ dist/site เดิม, --only=win|linux)
npm run e2e:desktop        # เปิดแอป Linux จริงบนจอเสมือน กับเซิร์ฟเวอร์ในเครื่อง (ไม่เพิ่มผู้เล่นทดสอบในเซิร์ฟเวอร์จริง)
```

ได้ไฟล์ `dist/desktop/MuayManager-<รุ่น>-win-x64.zip` และ `-linux-x64.zip` (ราว 160 และ 140 MB ส่วนใหญ่เป็นตัว Chromium)

- Electron รุ่น `45.2.3` ตรวจ SHA-256 กับค่าที่ Electron ประกาศทุกครั้ง เก็บไฟล์ไว้ใน `node_modules/.cache/muay-electron/`
- ไฟล์ .exe เปลี่ยนชื่อ ไอคอน และรุ่นเป็นของเกมด้วย `resedit` (ไม่ต้องใช้ Windows หรือ Wine)
- ตัดไฟล์ภาษาของ Chromium เหลือ อังกฤษ และ ไทย

## 3. ใช้งาน

- **Windows:** แตก zip แล้วเปิด `MuayManager.exe` ครั้งแรก Windows อาจขึ้น "Windows protected your PC" เพราะไฟล์ยังไม่ได้เซ็นชื่อผู้พัฒนา กด "More info" แล้ว "Run anyway" (บน Steam ไม่ต้องเซ็นก็ได้ Steam เป็นคนติดตั้งให้)
- **F11** หรือ **Alt+Enter** เต็มจอ/ออกจากเต็มจอ • ปิดแล้วเปิดใหม่ หน้าต่างกลับมาขนาดและตำแหน่งเดิม • เปิดซ้ำขณะเปิดอยู่ จะดึงหน้าต่างเดิมขึ้นมาแทน
- ลิงก์ออกนอกเกม (นโยบายความเป็นส่วนตัว) เปิดในเบราว์เซอร์ของเครื่อง • ปุ่มชวนดูไฟต์ คัดลอกลิงก์แทนการแชร์แบบมือถือ
- เครื่องที่การ์ดจอใช้ WebGL ไม่ได้ ยังเห็นเวที 3D ด้วยการวาดแบบซอฟต์แวร์ (ช้ากว่า)
- `--debug` (หรือ `MUAY_DEBUG=1`) เปิด F12 เครื่องมือนักพัฒนา • `--server=<url>` ชี้เซิร์ฟเวอร์อื่น (ใช้ทดสอบ)

## 4. ยังไม่ได้ทำ (ก่อนขึ้น Steam)

| งาน | ทำไม | ใครทำ |
|---|---|---|
| บัญชี Steamworks (ค่าธรรมเนียม 100 ดอลลาร์ต่อเกม ข้อมูลภาษีและบัญชีธนาคาร) และรหัสเกม (App ID) | ไม่มีรหัสเกมก็ทดสอบระบบของ Steam และอัปโหลดไม่ได้ | เจ้าของเกม |
| ต่อ Steamworks (`steamworks.js`): ความสำเร็จ (achievements) หน้าจอซ้อนของ Steam (overlay ต้องเปิดตัวเลือกพิเศษของ Chromium) | ผู้เล่น Steam คาดหวัง | Claude เมื่อได้ App ID |
| Steam Cloud ซิงก์โฟลเดอร์เซฟ | เล่นต่อข้ามเครื่องผ่าน Steam | ตั้งในหน้า Steamworks |
| หน้าจอแบบแนวนอนสำหรับคอม (เวทีซ้าย เมนูขวา) | ตอนนี้เป็นคอลัมน์เดียวกลางจอแบบเว็บบนคอม เลื่อนลงดูเมนู | Claude |
| ฟอนต์อยู่ในแอป | ตอนนี้โหลดจาก Google Fonts ไม่มีเน็ตจะเป็นฟอนต์สำรอง | Claude |
| เสียงพากย์อังกฤษ | ทางไป Steam ข้อ 1 ที่เหลือ | ต้องมีกุญแจ Gemini |
| ทดสอบบน Windows จริงและ Steam Deck | ตรวจที่นี่ได้แค่แอป Linux (Wine ในเครื่องทดสอบเปิดไม่ขึ้น) | เจ้าของเกม |
| เซ็นชื่อไฟล์ .exe (code signing) | ไม่ให้ Windows เตือนเมื่อแจกนอก Steam | ไม่จำเป็นบน Steam |
