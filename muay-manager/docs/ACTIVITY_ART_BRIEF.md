# ภาพกิจกรรมนอกเวที 7 ใบ — Muay Manager

ใช้กับกิจกรรม วิ่ง • พักผ่อนหย่อนใจ • พัก นวด ในหน้าซ้อม ภาพจะขยับช้า ๆ (เลื่อนและซูม) มีไอน้ำ แสงแดด ทับเพิ่มในเกม

## กติกาทุกใบ
- แนวนอน 3:2 (1536×1024) ลายเส้นเดียวกับภาพค่าย (01, 02): ภาพวาดเกมกึ่งสมจริง สีอุ่น สว่าง ไม่มืด
- นักมวยในภาพ: ชายไทยผิวแทน ผมสั้น **ไม่เห็นหน้าชัด** (หันหลัง มองด้านข้างไกล ๆ หรือเงาย้อนแสง) เพราะนักมวยในเกมแต่ละคนหน้าตาไม่เหมือนกัน
- ของสำคัญอยู่กลางภาพ 70% ขอบรอบ ๆ จะถูกตัดบ้างตอนภาพเลื่อน
- ไม่มีตัวหนังสือที่อ่านได้ ไม่มีโลโก้ ไม่มีคนจริง

## 7 ใบ
1. run_1 — วิ่งเช้า: นักมวยวิ่งบนถนนดินในหมู่บ้านตอนพระอาทิตย์ขึ้น ใส่เสื้อแขนกุดกางเกงขาสั้น หมอกบาง ๆ ทุ่งนาสองข้าง ต้นตาล มองจากด้านหลังเฉียง
2. run_2 — วิ่งขึ้นบันไดวัด: นักมวยวิ่งขึ้นบันไดนาคยาวไปวัดบนเขาตอนเช้า แสงแดดลอดต้นไม้ มองจากด้านล่างด้านหลัง
3. fun_1 — ตกปลา: นักมวยนั่งตกปลาริมคลองใต้ต้นไม้ใหญ่ตอนบ่าย มีถังปลาและกระติกน้ำ บรรยากาศสบาย ๆ มองจากด้านหลัง
4. fun_2 — กินข้าวกับที่บ้าน: นักมวยนั่งล้อมวงกินข้าวกับครอบครัวบนเสื่อในบ้านไม้ อาหารไทยหลายอย่าง ตอนเย็น แสงอุ่น นักมวยหันหลังให้กล้อง ครอบครัวหน้าไม่ชัด
5. fun_3 — หนังกลางแปลง: นักมวยกับเพื่อนนั่งดูหนังกลางแปลงในงานวัดตอนกลางคืน จอผ้าใหญ่ ไฟราว คนนั่งเสื่อ มองจากด้านหลังกลุ่มคนดู (กลางคืนแต่สว่างพอ)
6. rest_1 — นวดแผนไทย: นักมวยนอนคว่ำบนเสื่อในค่าย หมอนวดกำลังนวดขา มีขวดน้ำมันมวย ผ้าขาวม้า แสงแดดลอดหลังคา
7. rest_2 — ประคบสมุนไพร: นักมวยนั่งพักบนแคร่ไม้ หมอนวดใช้ลูกประคบสมุนไพรที่ยังมีไอน้ำประคบไหล่ หม้อนึ่งลูกประคบมีไอน้ำลอย
