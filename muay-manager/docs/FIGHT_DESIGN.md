# ออกแบบฉากชก — Muay Manager

เอกสารนี้ขยาย blueprint ข้อ 3 และ 4 ให้ละเอียดพอลงมือสร้าง
ตัวเลขทั้งหมดเป็นค่าเริ่มต้นสำหรับทดสอบ ยังไม่ได้ผ่านการจำลอง ค่าจริงจะมาจากการปรับสมดุลใน M0.7

---

## 1. หลักคิด: ไฟต์ที่ดีคือเรื่องเล่า ไม่ใช่การแลกหมัดจนเลือดหมด

เดโมตอนนี้สะใจเป็นจังหวะ แต่ทุกไฟต์เล่าเรื่องเดียวกัน: แลกกันไปเรื่อย ๆ แล้วมีคนล้มในยก 2
คนดูจะชอบเมื่อไฟต์มี 5 อย่างนี้

1. **อ่านออก** — ดูแล้วรู้ว่าใครได้เปรียบ เพราะอะไร (ขาเริ่มลาก การ์ดเริ่มตก)
2. **มีจังหวะขึ้นลง** — ช่วงดูเชิง ช่วงแลก ช่วงพัก ไม่ใช่ออกอาวุธถี่เท่ากันตลอด
3. **มีจุดพลิก** — ฝ่ายตามมีทางกลับมา และคนดูเห็นว่ามันกำลังจะเกิด
4. **หมัดใหญ่ต้องรู้สึกใหญ่** — หมัดธรรมดา 20 ครั้งเพื่อให้หมัดที่ 21 มีน้ำหนัก
5. **ไม่ซ้ำ** — สองไฟต์ติดกันต้องจบคนละแบบ

ทุกระบบข้างล่างออกแบบมาเพื่อ 5 ข้อนี้ และทั้งหมดอยู่ในตัวจำลอง ตัวเล่นภาพแค่เล่าให้เห็น

## 2. สิ่งที่เก็บจากเดโม และสิ่งที่ต้องเปลี่ยน

**เก็บไว้ (เจ้าของเกมอนุมัติแล้ว)**
- จังหวะท่า 3 ช่วง: ง้าง → กระทบ → เก็บ
- หยุดภาพตอนกระทบ จอสั่น สโลว์ตอนท่าไม้ตายและตอนล้ม แถบดำบนล่าง
- ป้ายชื่อท่าเด้งขึ้นตอนหมัดใหญ่ ประกายและเหงื่อกระเด็น คนดูโยกตามความตื่นเต้น
- กล้องซูมเข้าเมื่อเข้าวงใน
- บรรทัดบรรยายใต้เวที

**ต้องเปลี่ยน**

| ปัญหาในเดโม | ผลต่อคนดู | แนวแก้ |
|---|---|---|
| ผลกับภาพอยู่ในโค้ดก้อนเดียว ใช้ `Math.random()` | เล่นซ้ำไม่ได้ กล้องไม่รู้ล่วงหน้า | แยกตัวจำลอง ออกรายการเหตุการณ์ (ข้อ 9) |
| ผู้รับเปลี่ยนท่าหลังโดนแล้ว ไม่ได้เล่นคู่กับผู้ตี | หมัดดูไม่เข้าเป้าจริง | ท่าเข้าคู่ จัดระยะก่อนกระทบ (ข้อ 8.1) |
| ท่ามี 8 + 3 ท่า ออกเดี่ยว ๆ | ดูซ้ำเร็ว | 16 ท่า + คอมโบ + กอดปล้ำ + แม่ไม้ 12 ท่า (ข้อ 3–5) |
| พลังชีวิตลดอย่างเดียว ไม่มีผลตามเป้า | ไม่มีเรื่องเล่า แผนไม่มีความหมาย | ผลสะสมตามเป้า และอาการเมาหมัด (ข้อ 6) |
| ทุกไฟต์จบน็อกยก 2 | เดาได้ ไม่ลุ้น | ปรับอัตราความเสียหายและการฟื้น (ข้อ 10) |
| ไม่มีช่วงดูเชิง | เหนื่อยตา หมัดใหญ่ไม่เด่น | ผู้กำกับจังหวะไฟต์ (ข้อ 7) |

## 4. คอมโบ

เดโมออกชุดด้วยการสุ่ม 34% ว่าจะออกท่าต่อทันที ท่าที่ตามมาไม่เกี่ยวกับท่าแรก
ให้แทนด้วย **คอมโบที่ตั้งชื่อได้** 2–4 จังหวะ แต่ละสายมีชุดของตัวเอง

| สาย | คอมโบ | ลำดับ |
|---|---|---|
| ทุกสาย | หนึ่งสอง | แย็บ → หมัดตรง |
| ทุกสาย | หนึ่งสองเตะ | แย็บ → หมัดตรง → เตะลำตัว |
| หมัดหนัก | สามหมัด | แย็บ → หมัดตรง → ฮุก |
| หมัดหนัก | เจาะล่างขึ้นบน | หมัดลำตัว → ฮุก → หมัดเสย |
| จอมเตะ | ล่างบน | เตะขา → เตะก้านคอ |
| จอมเตะ | ถีบตามเตะ | ถีบ → เตะลำตัว → เตะลำตัว |
| เข่าศอก | ศอกคู่ | ศอกตี → ศอกกลับ |
| เข่าศอก | จับคอตีเข่า | เข้ากอด → เข่าโค้ง ×3 → ศอกตี |
| ฝีมือ | หลอกแล้วเตะ | แย็บหลอก → เตะก้านคอ |
| ฝีมือ | จับเตะสวน | จับเตะสวน → เตะตัดล่าง |

**กติกาคอมโบ**
- จังหวะถัดไปออกต่อได้เฉพาะเมื่อจังหวะก่อนหน้า **เข้าเป้าหรือถูกบัง** ถ้าถูกหลบ คอมโบขาดและเปิดช่องให้สวน
- แต่ละจังหวะที่เข้าติดกัน โอกาสบังของผู้รับลดลง และความเสียหายจังหวะสุดท้ายได้โบนัส
- จังหวะที่ 3 ขึ้นไปขึ้นตัวนับ "3 HIT" บนจอ และเสียงคนดูดังขึ้นตามจำนวน
- คอมโบถูกตัดได้ด้วยการสวน ผู้รับที่ค่าป้องกันสูงมีโอกาสสวนกลางคอมโบ

ผลที่ต้องการ: คนดูจำชุดประจำตัวนักมวยได้ และเห็นจังหวะ "เข้า เข้า เข้า ปิด" ที่สะใจกว่าหมัดเดี่ยว

## 6. ระบบที่ทำให้ไฟต์มีเรื่องเล่า

### 6.1 ผลสะสมตามเป้า

| เป้า | ค่าสะสม | ผลในเกม | สิ่งที่คนดูเห็น |
|---|---|---|---|
| ขา | 0–100 | ความเร็วเดินและความเร็วเตะลดลง โอกาสหลบลดลง | ขาแดง เดินกะเผลก ยืนหนักขาหลัง |
| ลำตัว | 0–100 | แรงฟื้นช้าลง เพดานแรงลดลง | ซี่โครงแดง หอบ การ์ดตก |
| หัว | 0–100 | โอกาสเมาหมัดและล้มสูงขึ้น | หน้าบวม แผลแตก โยกหัวช้าลง |

ค่าสะสมไม่ฟื้นระหว่างยก (ต่างจากพลังชีวิตและแรง) จึงเป็นสิ่งที่แผนระยะยาวสร้างได้
พี่เลี้ยงอ่านค่านี้แล้วแนะนำ เช่น "ขาหน้าเขาเริ่มช้า เตะขาต่อ"

### 6.2 อาการเมาหมัด (สถานะใหม่ ระหว่าง "โดน" กับ "ล้ม")

- เกิดเมื่อโดนหัวแรง ๆ หรือโดนหัวสะสมมาก นาน 1.5–3 วินาที
- ระหว่างเมา: บังได้น้อยมาก หลบไม่ได้ ออกอาวุธช้า เดินเซ
- ฝ่ายตรงข้ามรู้ และเร่งออกอาวุธ (**ช่วงไล่ถล่ม**)
- จบได้ 3 ทาง: โดนต่อจนล้ม • รอดด้วยการเข้ากอด • ระฆังช่วย
- นี่คือช่วงที่ลุ้นที่สุดของไฟต์ กล้องซูม เสียงคนดูดังสุด ปี่กลองเร่ง

เดโมข้ามจาก "โดน" ไป "ล้ม" ทันทีด้วยการสุ่ม คนดูจึงไม่ได้ลุ้น การเพิ่มช่วงนี้คือการเปลี่ยนที่ให้ผลมากที่สุดต่อความเร้าใจ

### 6.3 การกอดปล้ำ (เอกลักษณ์มวยไทย)

- เข้าได้เมื่ออยู่วงในและฝ่ายใดฝ่ายหนึ่งเลือกเข้ากอด (สายเข่าศอกเลือกบ่อย คนเมาหมัดเลือกเพื่อเอาตัวรอด)
- ระหว่างกอด: ใช้ได้เฉพาะเข่าโค้ง ศอกตี และแม่ไม้หักคอเอราวัณ แย่งตำแหน่งกันด้วยค่าเตะเข่าและความอึด
- จบเมื่อ: มีคนสะบัดหลุด • กรรมการแยกหลัง 4 วินาที • มีคนล้ม
- สายหมัดหนักและจอมเตะเสียเปรียบในวงกอด จึงต้องถีบหรือเดินวงเพื่อไม่ให้ถูกเข้า — **ระยะกลายเป็นการต่อสู้อีกชั้น**

### 6.4 ตำแหน่งบนเวที

- ถูกดันติดเชือก: ถอยไม่ได้ โอกาสหลบลดลง โดนถีบแล้วเด้งกลับเข้าหาหมัด
- ติดมุม: เสียเปรียบมากกว่าติดเชือก ต้องเข้ากอดหรือแลกเพื่อออก
- ผู้ที่คุมกลางเวทีได้คะแนนเล็กน้อย

### 6.5 แรงใจและการกลับมา

- **คะแนนตาม:** นักมวยที่ตามหลังในยกสุดท้ายเกจท่าไม้ตายขึ้นเร็วขึ้น และเลือกท่าเสี่ยงมากขึ้น
- **ลุกแล้วสู้:** ลุกจากการนับแล้วได้ช่วงสั้น ๆ ที่ล้มซ้ำยากขึ้น เพื่อไม่ให้ล้มครั้งแรกเท่ากับจบ
- **ค่าคาง:** ลดโอกาสเมาหมัดและล้ม เพิ่มโอกาสลุก ทำให้นักมวยสาย "อึดทน" เป็นตัวตนที่เล่นได้
- ทั้งหมดนี้จำกัดช่วงไว้ เพื่อไม่ให้รู้สึกว่าเกมช่วยฝ่ายแพ้จนผลไม่ยุติธรรม

## 7. ผู้กำกับจังหวะไฟต์ (อยู่ในตัวจำลอง)

เพื่อไม่ให้ออกอาวุธถี่เท่ากันตลอด ไฟต์แบ่งเป็นช่วงที่เปลี่ยนตามสถานการณ์
ตัวจำลองเป็นผู้ตัดสินช่วง และเขียนลงรายการเหตุการณ์ ตัวเล่นภาพใช้เลือกกล้องและเสียง

| ช่วง | เกิดเมื่อ | พฤติกรรมนักมวย | กล้องและเสียง |
|---|---|---|---|
| ดูเชิง | ต้นยก หลังกรรมการแยก หลังแลกหนัก | เดินวง แย็บวัดระยะ ถีบหลอก ออกอาวุธน้อย | กล้องกว้าง ปี่กลองช้า คนดูเงียบ |
| แลก | ทั้งคู่อยู่ในระยะและแรงเหลือ | คอมโบ สวนกัน | กล้องกลาง ปี่กลองปกติ |
| ไล่ถล่ม | ฝ่ายหนึ่งเมาหมัดหรือติดมุม | ฝ่ายได้เปรียบออกรัว ฝ่ายเสียเปรียบเอาตัวรอด | กล้องซูม สั่น ปี่เร่ง คนดูตะโกน |
| กอดปล้ำ | เข้าวงกอด | เข่า ศอก แย่งตำแหน่ง | กล้องใกล้ มุมต่ำ |
| หายใจ | ทั้งคู่แรงต่ำ | ถอยห่าง ฟื้นแรง | กล้องถอย เห็นหอบ |
| โค้งสุดท้าย | 8 วินาทีสุดท้ายของยก | ทั้งคู่เร่ง ยอมเสี่ยง | เสียงเคาะไม้เตือน ปี่เร่งสุด |

การมีช่วง "ดูเชิง" และ "หายใจ" ช่วยแก้ปัญหาสมดุลไปพร้อมกัน: ความเสียหายต่อวินาทีลดลงเอง ไฟต์จึงยาวถึงยก 3 และถึงการตัดสินคะแนนได้

## 8. การนำเสนอ

### 8.1 ท่าเข้าคู่ (สำคัญที่สุด)

เพราะตัวเล่นภาพรู้ผลล่วงหน้าจากรายการเหตุการณ์ จึงทำได้ดังนี้
1. อ่านเหตุการณ์ `move` พร้อม `hit` ที่ตามมา รู้ว่าจะ โดน / บัง / หลบ / พลาด ตั้งแต่จังหวะง้าง
2. เลื่อนระยะยืนทั้งคู่ให้ปลายอาวุธถึงเป้าพอดีตอนเฟรมกระทบ
3. ผู้รับเริ่มท่ารับ **ก่อน** กระทบ: ยกการ์ดทันก่อนหมัดถึง โยกหัวทันก่อนเท้าผ่าน
4. ท่าโดนเลือกตามทิศและเป้า: ฮุกทำหัวสะบัดข้าง เสยทำหัวเงย เข่าทำตัวงอ เตะขาทำขาพับ
5. ระดับความแรง 3 ระดับต่อท่าโดน: เบา (แค่สะดุ้ง) กลาง (เซ) หนัก (ถอยหลายก้าว)

### 8.2 จังหวะกระทบ

| ความแรง | หยุดภาพ | จอสั่น | เอฟเฟกต์ | เสียง |
|---|---|---|---|---|
| เบา | 30 ms | น้อย | ประกายเล็ก | เสียงแปะ |
| กลาง | 60 ms | กลาง | ประกาย เหงื่อ | เสียงตุ้บ |
| หนัก | 90 ms | มาก | ประกายทอง เหงื่อ ป้ายชื่อท่า | เสียงตุ้บ + เบสต่ำ |
| ท่าไม้ตาย / หมัดน็อก | 120 ms + สโลว์ | มากสุด | จอขาววาบ เส้นความเร็ว | เสียงเฉพาะท่า แล้วเงียบครึ่งวินาที |

ความเงียบหลังหมัดน็อกก่อนเสียงคนดูระเบิด คือสิ่งที่ทำให้รู้สึกหนัก

### 8.3 ผู้กำกับกล้อง

อ่านรายการเหตุการณ์ล่วงหน้า 1–2 วินาที
- ปกติ: ด้านข้าง ตามจุดกึ่งกลาง ซูมตามระยะห่าง
- ก่อนหมัดใหญ่ที่จะเข้า: ค่อย ๆ ซูมเข้าตั้งแต่จังหวะง้าง
- ท่าไม้ตาย: ตัดมุมเฉพาะท่า แล้วกลับ
- ล้ม: สโลว์ ตามตัวคนล้มลงพื้น แล้วตัดไปหน้าผู้ชนะ
- หมัดน็อก: **เล่นซ้ำทันที 1 ครั้งจากอีกมุมแบบสโลว์** ทำได้โดยไม่มีต้นทุนเพราะเป็นรีเพลย์จากเหตุการณ์อยู่แล้ว
- จำกัดการตัดกล้องไม่เกิน 1 ครั้งต่อ 4 วินาที ไม่ให้เวียนหัว

### 8.4 เสียง

- **ปี่กลอง:** ดนตรีวนตามช่วงของข้อ 7 เร่งจังหวะตามยกและตามความตื่นเต้น เป็นเอกลักษณ์ที่เกมอื่นไม่มี
- **คนดู:** 4 ชั้น — พึมพำ ฮือ เชียร์ ระเบิด — ผสมตามค่าความตื่นเต้น และตะโกนรับจังหวะเตะเข่าที่เข้าเป้า
- **กระทบ:** แยกหมัด ศอก เข่า เตะ บัง และเตะโดนการ์ด อย่างละ 3 แบบสุ่มสลับ
- **กรรมการ:** นับ แยก ชี้มุม
- **พี่เลี้ยง:** ตะโกนสั้น ๆ จากมุมตามสถานการณ์
- M0 สังเคราะห์เสียงด้วย WebAudio เหมือนเดโม เสียงจริงมาใน M1

### 8.5 ร่องรอยบนตัวและจอ

- รอยแดงสะสมตามค่าในข้อ 6.1 แผลแตกที่หน้า เหงื่อมากขึ้นตามยก
- ท่ายืนเปลี่ยนตามสภาพ: การ์ดตก หอบ ขาลาก
- แถบสถานะบนจอ: พลังชีวิต แรง เกจท่าไม้ตาย และไอคอน 3 เป้าที่เปลี่ยนสีตามค่าสะสม
- บรรทัดบรรยาย: ผู้บรรยายเรียกชื่อคอมโบและจุดพลิก

### 8.6 หลังไฟต์

- ภาพสโลว์หมัดตัดสิน
- สรุปสถิติ: ท่าที่เข้าเป้ามากสุด เป้าที่โดนมากสุด คอมโบยาวสุด จุดพลิกของไฟต์
- ประโยคเดียวบอกเหตุผลแพ้ชนะ เช่น "แพ้เพราะโดนเตะขา 14 ครั้งจนเดินไม่ทัน" เพื่อลดความรู้สึกว่าเป็นดวง
- ปุ่มแชร์รีเพลย์

## 9. รายการเหตุการณ์ (เพิ่มจาก blueprint ข้อ 3.7)

ชนิดเหตุการณ์ที่เพิ่มเพื่อรองรับระบบข้างบน

| type | ใช้เมื่อ | ข้อมูลสำคัญ |
|---|---|---|
| `phase` | ช่วงของไฟต์เปลี่ยน | `phase`: feel / exchange / flurry / clinch / breather / final |
| `combo` | เริ่มคอมโบที่ตั้งชื่อได้ | `id`, `by`, จำนวนจังหวะ |
| `stun` / `stun_end` | เมาหมัด | `on`, ระยะเวลา, เหตุที่จบ |
| `clinch` / `break` | เข้าและออกจากวงกอด | ผู้เข้า เหตุที่แยก |
| `ropes` | ติดเชือกหรือมุม | `on`, `corner` |
| `wear` | ค่าสะสมตามเป้าข้ามเกณฑ์ | `on`, `zone`, ระดับ |
| `cut` | แผลแตก | `on` |
| `advice` | คำแนะนำพี่เลี้ยงระหว่างยก | รหัสข้อความ และสถิติที่อ้าง |

เหตุการณ์ `hit` เพิ่ม `sev` (เบา / กลาง / หนัก) `comboIdx` และ `pos` ของทั้งสองฝ่าย
เหตุการณ์ `move` มี `tHit` บอกเวลากระทบล่วงหน้า เพื่อให้กล้องและท่าเข้าคู่เตรียมตัวได้

ตัวจำลองส่งตำแหน่งนักมวยเป็นจุดตามเวลาด้วย ตัวเล่นภาพใช้เดินตาม ไม่คำนวณการเดินเอง

## 10. แนวทางแก้สมดุล

ปัญหา: เดโมจบน็อกทุกไฟต์ ส่วนใหญ่ในยก 2 ไม่มีไฟต์ไหนถึงคะแนน

ลำดับที่จะลอง ทีละอย่าง วัดผลด้วยการจำลอง 2,000 ไฟต์ทุกครั้ง
1. ช่วงดูเชิงและหายใจจากข้อ 7 (ลดจำนวนอาวุธต่อยก)
2. ให้การน็อกมาจากอาการเมาหมัดและการล้มเป็นหลัก ไม่ใช่พลังชีวิตหมด: ลดตัวคูณความเสียหายรวม และให้พลังชีวิตฟื้นช่วงพักยกมากขึ้น
3. ผูกโอกาสล้มกับค่าสะสมที่หัวและค่าคาง แทนการสุ่มจากความแรงหมัดเดียว
4. คะแนนตัดสินรวมการคุมเวที คอมโบ และการทำล้ม เพื่อให้ไฟต์ครบยกมีผู้ชนะที่อธิบายได้

## 11. สิ่งที่วัดว่า "สนุก" ได้ด้วยตัวเลข

การจำลองจำนวนมากรายงานค่าเหล่านี้คู่กับเป้าสมดุล เพื่อจับไฟต์ที่น่าเบื่อก่อนถึงมือคนดู

| ตัววัด | เป้าเริ่มต้น | เหตุผล |
|---|---|---|
| จำนวนครั้งที่ผู้นำคะแนนเปลี่ยนต่อไฟต์ | เฉลี่ย 1 ขึ้นไป | มีจุดพลิก |
| ไฟต์ที่มีช่วงเมาหมัดอย่างน้อย 1 ครั้ง | 60% ขึ้นไป | มีช่วงลุ้น |
| ไฟต์ที่ผู้ถูกเมาหมัดรอดได้ | ราว 50% ของครั้งที่เมา | ลุ้นได้ทั้งสองทาง |
| จำนวนท่าต่างชนิดที่ใช้ต่อไฟต์ | 9 ขึ้นไป | หลากหลาย |
| คอมโบ 3 จังหวะขึ้นไปต่อไฟต์ | 3–6 | สะใจแต่ไม่เฟ้อ |
| ท่าไม้ตายต่อไฟต์ | 2–4 และเข้าเป้าราวครึ่ง | พิเศษจริง |
| ช่วงเงียบยาวสุดที่ไม่มีอาวุธเข้าเป้า | ไม่เกิน 5 วินาที | ไม่อืด |
| ไฟต์ที่ตัดสินด้วยคะแนนห่างไม่เกิน 10% | ราวหนึ่งในสามของไฟต์ครบยก | สูสี |

ตัวเลขผ่านไม่ได้แปลว่าสนุก การยืนยันสุดท้ายคือเจ้าของเกมดูแล้วบอกว่าดีกว่าเดโม
