# แผนออนไลน์และลงสโตร์ — Muay Manager

สถานะ: ร่างแรก 13 พ.ย. 2026 ยังไม่ได้เริ่มทำ รอเจ้าของเกมตอบคำถามข้อ 6

## 1. ภาพรวม

```
มือถือ (แอป iOS / Android)                     VPS ของเจ้าของเกม
┌──────────────────────────────┐     HTTPS     ┌──────────────────────────────────┐
│ เกมเดิม (three.js) ห่อด้วย     │ ───────────▶ │ nginx (SSL) → เซิร์ฟเวอร์เกม Node.js │
│ Capacitor ไฟล์ทั้งหมดอยู่ในแอป  │ ◀─────────── │   ตัวจำลองไฟต์ชุดเดียวกับในเกม       │
│ เล่นออฟไลน์ได้ ซิงก์เมื่อมีเน็ต   │  ผลไฟต์/เซฟ   │ PostgreSQL: บัญชี เซฟ อันดับ ร้านค้า  │
└──────────────────────────────┘               └──────────────────────────────────┘
```

- **ไฟต์จัดอันดับจำลองที่เซิร์ฟเวอร์** ตัวจำลองเป็น JavaScript ล้วน ให้ผลเดิมทุกครั้งเมื่อข้อมูลเข้าเดิม จึงย้ายไปรันบน VPS ได้ตรง ๆ แอปส่งแค่ "แผนการชก" ไป เซิร์ฟเวอร์ส่งรายการเหตุการณ์กลับมาให้แอปเล่นภาพ แก้ค่าพลังในเครื่องแล้วโกงอันดับไม่ได้ (ตอนนี้โกงได้ จดไว้ใน `STATUS.md` แล้ว)
- **ซ้อม แต่งตัว ไฟต์ท้องถิ่น** เล่นในเครื่องได้เลย ส่งเซฟขึ้นเซิร์ฟเวอร์เมื่อออนไลน์ เซิร์ฟเวอร์ตรวจว่าค่าพลังขึ้นสมเหตุผล
- **ไฟล์เกมทั้งหมดอยู่ในแอป** (โมเดล เสียง three.js) ไม่โหลดหน้าเว็บจากเน็ต Apple ไม่รับแอปที่เป็นแค่หน้าเว็บห่อ (ข้อ 4.2) และเกมจะเปิดเร็ว
- **พากย์ชื่อนักมวย** ทำได้เมื่อมีเซิร์ฟเวอร์: ตอนสร้างนักมวย เซิร์ฟเวอร์สั่ง TTS อ่านชื่อครั้งเดียวแล้วเก็บไว้ (คีย์ TTS อยู่บนเซิร์ฟเวอร์ ไม่อยู่ในแอป)

## 3. VPS ต้องมี

- Ubuntu 22.04 หรือ 24.04 อย่างน้อย 2 vCPU, RAM 2 GB, ดิสก์ 40 GB (ช่วงแรกพอ ไฟต์หนึ่งจำลองไม่ถึง 5 มิลลิวินาที)
- โดเมนของตัวเอง ชี้มาที่ VPS (ใช้กับ SSL และหน้านโยบายความเป็นส่วนตัวที่สโตร์บังคับ)
- เปิดพอร์ต 80 และ 443 เท่านั้น เข้าเครื่องด้วยกุญแจ SSH ไม่ใช้รหัสผ่าน
- **ห้ามส่งรหัสผ่านหรือกุญแจ SSH ในแชต** สคริปต์ติดตั้งจะให้เจ้าของเกมรันเองบนเครื่อง

## 6. คำถามถึงเจ้าของเกม

1. VPS: ผู้ให้บริการ ระบบปฏิบัติการ สเปก และอยู่ประเทศไหน (ผู้เล่นไทยเป็นหลัก เครื่องในสิงคโปร์หรือไทยจะเร็วกว่า)
2. มีโดเมนแล้วหรือยัง ชื่ออะไร
3. สมัครบัญชีนักพัฒนา Apple และ Google แล้วหรือยัง (ชื่อบุคคลหรือบริษัท)
4. หารายได้แบบไหน: ฟรีและขายชุด/สีผม • ซื้อครั้งเดียว • โฆษณา • ยังไม่หา
5. ชื่อเกมจริง (Muay Manager เป็นชื่อทำงาน ต้องเช็กว่าไม่ซ้ำเกมอื่นในสโตร์)
6. เปิดตัวภาษาไทยอย่างเดียว หรือไทยกับอังกฤษพร้อมกัน
7. ลงทั้ง iOS และ Android หรือเริ่มที่ Android ก่อน (ตรวจเร็วกว่า ทดสอบง่ายกว่า ไม่ต้องใช้ Mac)
