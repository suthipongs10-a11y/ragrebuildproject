# แผนออนไลน์และลงสโตร์ — Muay Manager

สถานะ: ร่างแรก 13 พ.ย. 2026 ยังไม่ได้เริ่มทำ รอเจ้าของเกมตอบคำถามข้อ 6

## 1. ภาพรวม

```
มือถือ (แอป iOS / Android)                     VPS ของเจ้าของเกม
┌──────────────────────────────┐     HTTPS     ┌──────────────────────────────────┐
│ เกมเดิม (three.js) ห่อด้วย     │ ───────────▶ │ nginx (SSL) → เซิร์ฟเวอร์เกม Node.js │
│ Capacitor ไฟล์ทั้งหมดอยู่ในแอป  │ ◀─────────── │   ตัวจำลองไฟต์ชุดเดียวกับในเกม       │
│ เล่นออฟไลน์ได้ ซิงก์เมื่อมีเน็ต   │  ผลไฟต์/เซฟ   │ PostgreSQL: บัญชี เซฟ อันดับ ร้านค้า  │
└──────────────────────────────┘               └──────────────────────────────────┘
```

- **ไฟต์จัดอันดับจำลองที่เซิร์ฟเวอร์** ตัวจำลองเป็น JavaScript ล้วน ให้ผลเดิมทุกครั้งเมื่อข้อมูลเข้าเดิม จึงย้ายไปรันบน VPS ได้ตรง ๆ แอปส่งแค่ "แผนการชก" ไป เซิร์ฟเวอร์ส่งรายการเหตุการณ์กลับมาให้แอปเล่นภาพ แก้ค่าพลังในเครื่องแล้วโกงอันดับไม่ได้ (ตอนนี้โกงได้ จดไว้ใน `STATUS.md` แล้ว)
- **ซ้อม แต่งตัว ไฟต์ท้องถิ่น** เล่นในเครื่องได้เลย ส่งเซฟขึ้นเซิร์ฟเวอร์เมื่อออนไลน์ เซิร์ฟเวอร์ตรวจว่าค่าพลังขึ้นสมเหตุผล
- **ไฟล์เกมทั้งหมดอยู่ในแอป** (โมเดล เสียง three.js) ไม่โหลดหน้าเว็บจากเน็ต Apple ไม่รับแอปที่เป็นแค่หน้าเว็บห่อ (ข้อ 4.2) และเกมจะเปิดเร็ว
- **พากย์ชื่อนักมวย** ทำได้เมื่อมีเซิร์ฟเวอร์: ตอนสร้างนักมวย เซิร์ฟเวอร์สั่ง TTS อ่านชื่อครั้งเดียวแล้วเก็บไว้ (คีย์ TTS อยู่บนเซิร์ฟเวอร์ ไม่อยู่ในแอป)

## 3. VPS ต้องมี

- Ubuntu 22.04 หรือ 24.04 อย่างน้อย 2 vCPU, RAM 2 GB, ดิสก์ 40 GB (ช่วงแรกพอ ไฟต์หนึ่งจำลองไม่ถึง 5 มิลลิวินาที)
- โดเมนของตัวเอง ชี้มาที่ VPS (ใช้กับ SSL และหน้านโยบายความเป็นส่วนตัวที่สโตร์บังคับ)
- เปิดพอร์ต 80 และ 443 เท่านั้น เข้าเครื่องด้วยกุญแจ SSH ไม่ใช้รหัสผ่าน
- **ห้ามส่งรหัสผ่านหรือกุญแจ SSH ในแชต** สคริปต์ติดตั้งจะให้เจ้าของเกมรันเองบนเครื่อง

## 8. กันโกง: เซิร์ฟเวอร์เป็นคนตัดสิน (14 พ.ย. 2026 รอเจ้าของเกมเลือกเวลาเริ่ม)

### ตอนนี้โกงได้ตรงไหน
ทุกอย่างคำนวณในเครื่องผู้เล่น เซิร์ฟเวอร์ (`functions/api`) แค่เก็บเอกสารและตรวจว่าเขียนของตัวเอง

| จุด | วิธีโกง |
|---|---|
| ค่าพลัง เงิน ชื่อเสียง RP | แก้ใน localStorage หรือส่งเข้า `/api` ตรง ๆ |
| ตารางอันดับ | RP มาจากเครื่องผู้เล่นเอง |
| ท้าชก: ค่าพลัง | ผู้ท้าเขียนค่าพลังของตัวเองลงคำท้า |
| ท้าชก: เลขไฟต์ | ผู้ท้าสุ่มเลขเอง ลองจำลองหลายเลขจนได้เลขที่ชนะแล้วค่อยส่ง |
| ท้าชก: แผน | ผู้ถูกท้าเห็นเลขไฟต์และแผนอีกฝ่ายก่อนตอบ จำลองทุกแผนหาแผนที่ชนะได้ |
| ท้าชก: ผล | แต่ละเครื่องบันทึกผลของตัวเอง แพ้แล้วไม่บันทึกก็ได้ |
| เวลา | วันและแรงซ้อมอิงนาฬิกาเครื่อง |

เล่นกับเพื่อนพอได้ ห้ามเปิดสาธารณะหรือขายของด้วยแบบนี้

### หลักที่จะใช้
1. **เซิร์ฟเวอร์เป็นเจ้าของข้อมูล** เงิน ค่าพลัง ความล้า RP ประวัติ ของ อยู่ที่เซิร์ฟเวอร์ เครื่องผู้เล่นส่งแค่คำสั่ง (ซ้อมท่านี้ ซื้อชิ้นนี้ ตั้งแผนนี้ ขึ้นชกคู่นี้) เซิร์ฟเวอร์ตรวจกับกติกาใน `data.js` ชุดเดียวกับเกม แล้วแก้ข้อมูลเอง
2. **ไฟต์ที่ให้รางวัลจำลองที่เซิร์ฟเวอร์ทุกไฟต์** เซิร์ฟเวอร์สุ่มเลขไฟต์ **หลังล็อกแผนทั้งสองฝ่ายแล้ว** ส่ง {เลขไฟต์ ค่าพลัง แผน รุ่นตัวจำลอง} ให้เครื่องเล่นภาพ ตัวจำลองให้ผลเดิมทุกครั้ง ภาพจึงตรงกับผลที่บันทึกโดยไม่ต้องส่งรายการเหตุการณ์ (เฉลี่ย 59 KB ต่อไฟต์)
3. **แก้แผนตอนพักยก** ส่งแผนยกถัดไปให้เซิร์ฟเวอร์ แล้วเซิร์ฟเวอร์จำลองใหม่ด้วยแผนรายยก (`plans[ฝ่าย][ยก]` ตัวจำลองรองรับแล้ว) ยกที่ชกไปแล้วผลไม่เปลี่ยน
4. **ใช้นาฬิกาเซิร์ฟเวอร์** นับวัน แรงซ้อม เวลานัดท้าชก
5. **ไฟต์ย้อนหลัง** เก็บแค่ข้อมูลเข้า + รุ่นตัวจำลอง เก็บตัวจำลองรุ่นเก่าไว้เพื่อเปิดไฟต์เก่าหลังปรับสมดุล
6. **บัญชีจริง** ล็อกอิน (Google / Apple / อีเมล) ย้ายเครื่องได้ ลบบัญชีได้ (สโตร์บังคับ)
7. **กันปั๊ม** จำกัดรางวัลจากคู่เดิมซ้ำ ๆ จำกัดการสมัคร (Cloudflare Turnstile) จำกัดความถี่คำขอ

กันไม่ได้แต่ไม่เสียหาย: รู้ผลก่อนดูจบ (ผลล็อกไปแล้ว) • ใช้บอทกดซ้อมแทน (มีเพดานต่อวัน)

### ที่พร้อมแล้วในโค้ด
ตัวจำลองไม่มีโค้ดภาพและไม่ใช้ตัวสุ่มหรือนาฬิกาของเครื่อง (`sim.js`) • ค่ากติกาอยู่ใน `data.js` • ตัวกรองแผนและค่าพลังที่รับมาจากผู้เล่นอื่น (`cleanPlan` `cleanSpec`) • ทดสอบว่าเลขไฟต์เดิมได้ผลเดิม (`npm test`)

### ต้นทุนการคำนวณ (วัด 14 พ.ย. 2026)
- 6 มิลลิวินาทีต่อไฟต์ (Node ในเครื่องทดสอบ) เฉลี่ย 493 เหตุการณ์
- Cloudflare Workers แผนฟรีให้ CPU 10 มิลลิวินาทีต่อคำขอ เฉียดเกินไป ใช้แผน Workers Paid 5 USD ต่อเดือน หรือรันบน VPS (คอร์เดียวราว 160 ไฟต์ต่อวินาที)
- คนเล่นเยอะ: Workers + D1 ขยายเองอัตโนมัติ ถ้าถามข้อมูลซ้ำบ่อยจนเปลือง ค่อยเปลี่ยนการอัปเดตสดจากถามซ้ำทุก 8 วินาทีเป็น WebSocket (Durable Objects)

## 6. คำถามถึงเจ้าของเกม

1. VPS: ผู้ให้บริการ ระบบปฏิบัติการ สเปก และอยู่ประเทศไหน (ผู้เล่นไทยเป็นหลัก เครื่องในสิงคโปร์หรือไทยจะเร็วกว่า)
2. มีโดเมนแล้วหรือยัง ชื่ออะไร
3. สมัครบัญชีนักพัฒนา Apple และ Google แล้วหรือยัง (ชื่อบุคคลหรือบริษัท)
4. หารายได้แบบไหน: ฟรีและขายชุด/สีผม • ซื้อครั้งเดียว • โฆษณา • ยังไม่หา
5. ชื่อเกมจริง (Muay Manager เป็นชื่อทำงาน ต้องเช็กว่าไม่ซ้ำเกมอื่นในสโตร์)
   - 14 พ.ย. 2026 เจ้าของเกมเสนอ "สุดยอดมวยไทย": คำนี้เป็นชื่องานมวยจริงอยู่แล้ว ("สุดยอดมวยไทย นายขนมต้ม") และเป็นคำทั่วไปในพาดหัวข่าวมวย ค้นเจอยาก และอาจชนเครื่องหมายการค้า ข้อเสนอ: ชื่อเฉพาะ + คำอธิบาย เช่น "Muay Manager: ค่ายมวยไทย" แล้วค้นสโตร์และทะเบียนเครื่องหมายการค้า (กรมทรัพย์สินทางปัญญา) ก่อนตัดสิน
   - ค้นเมื่อ 14 พ.ย. 2026 ยังไม่เจอเกมผู้จัดการค่ายที่เป็นมวยไทยล้วน มีแต่เกมผู้จัดการ MMA ที่มีมวยไทยเป็นสายหนึ่ง คำว่า "ผู้จัดการค่ายมวย" จึงควรอยู่ในชื่อหรือคำบรรยายใต้ชื่อ
6. เปิดตัวภาษาไทยอย่างเดียว หรือไทยกับอังกฤษพร้อมกัน
7. ลงทั้ง iOS และ Android หรือเริ่มที่ Android ก่อน (ตรวจเร็วกว่า ทดสอบง่ายกว่า ไม่ต้องใช้ Mac)
