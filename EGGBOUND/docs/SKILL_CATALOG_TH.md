# คลังกลไกสกิล Eggbound (Skill Mechanics Catalog)

> เจ้าของตัดสิน 2026-10-14: เอา **แนวคิดกลไก** จาก Summoners War และ Dota มาใช้ได้ แต่ **ตั้งชื่อใหม่ของเราเอง**
> และ **ห้ามยกชุดสกิลของฮีโร่/มอนตัวใดตัวหนึ่งมาทั้งชุด** (กติกาลิขสิทธิ์ข้อ 2 ใน CLAUDE.md) — หยิบได้ทีละกลไกแบบทั่วไป
> แล้วผสมกับธีมตำนานของมอนตัวนั้น
>
> ใช้ไฟล์นี้ตอนออกแบบสกิลมอนตัวใหม่ทุกครั้ง: เลือก "กลไกเด่น" 1 อย่างที่ยังไม่มีใครในธาตุเดียวกันใช้ แล้วจดชื่อมอนลงคอลัมน์ "ใช้โดย"

## กติกาการออกแบบ
1. ทุกตัวมี **สกิล 3 สกิล + สกิลผู้นำ** เหมือนเดิม · มอนตัวใหม่มี **พาสซีฟประจำตัว** (`SpeciesDef.passive`) ได้อีก 1 อย่าง แบบ SW
   — ทุกร่างใช้ได้ (ร่างปกติ ร่างหายาก ร่างวิวัฒน์) · ร่างหายากยังได้ **พาสซีฟร่างหายาก** (`rarePassive`) เป็นอันที่ 4 เหมือนเดิม
2. **สกิล 1** = ตีพื้นฐาน มักติดเครื่องหมายธาตุ (จุดขายปฏิกิริยาธาตุ) ซ้ำแนวกันได้
3. **สกิล 2 และ 3 ห้ามเหมือนกันทุกอย่างกับของตัวอื่น** — `tests/mechanics.ts` ตรวจให้อัตโนมัติ
   (A05/C01 สกิล 2 และ A07/C03 สกิล 2 มีก่อนกติกา ยกเว้นไว้)
4. มอนเดิม **ไม่แตะ** (กติกา "ห้ามลดพลังมอนเรา") — กลไกใหม่ใช้กับมอนตัวใหม่ (BATCH21 + ภพ 4 + บอส)
5. กลไกใหม่ทั้งหมด deterministic — สุ่มด้วย RNG ของการต่อสู้เฉพาะตอนที่มีกลไกนั้นในสนาม (มอนเดิมผลเหมือนเดิมเป๊ะ)

## A. สถานะ (status) — `types.ts StatusId`
| ชื่อในเกม | key | ผล | แนวคิดจาก |
|---|---|---|---|
| เผาไหม้ / พิษ | burn / poison | เสีย HP 5% ต่อเทิร์น (บอส 1.2%) | ทั่วไป |
| มึน / หลับ | stun / sleep | ข้ามเทิร์น (หลับตื่นเมื่อโดนตี) · บอสต้านทาน | ทั่วไป |
| ตาบอด | blind | ตีเดี่ยวพลาด 50% | ทั่วไป |
| ลด/เพิ่ม ATK DEF SPD · คริขึ้น | atk_down … crit_up | ±30% / DEF ×1.4 / ×0.5 · คริ +20% | SW |
| โล่ · ฟื้นฟู | shield / regen | ดูดซับดาเมจ · ฮีล 10%/เทิร์น | SW |
| อมตะ · ภูมิคุ้มกัน · ปกป้อง | invincible / immunity / protect | ไม่โดนดาเมจ · กันสถานะร้าย · เพื่อนรับดาเมจครึ่ง | SW |
| ยั่วยุ · ผนึกสกิล · ห้ามฮีล | provoke / silence / unheal | ต้องตีคนยั่ว · ใช้ได้แค่สกิล 1 · ฮีลไม่เข้า | SW / Dota |
| ตราบาป | brand | รับดาเมจ +25% | SW |
| ระเบิดเงา | bomb | ครบเวลาระเบิด + มึน | SW |
| **แช่แข็ง** ใหม่ | freeze | ข้ามเทิร์น · โดนศัตรูตีครั้งถัดไป +30% แล้วน้ำแข็งแตก · บอสต้านทาน | SW (freeze) + กลไกแตกของเราเอง |
| **สับสน** ใหม่ | confuse | ทุกเทิร์น 50% ตีพวกเดียวกันด้วยสกิล 1 (ไม่ทำให้ตาย) · บอสต้านทาน | Dota/RPG ทั่วไป |

## B. ตัวปรับสกิล (SkillDef)
| ชื่อในเกม | field | ผล | แนวคิดจาก |
|---|---|---|---|
| ไม่สนใจ DEF | ignoreDef | ข้าม DEF เป้าหมายบางส่วน | SW |
| **ตีรัว** ใหม่ | hits | แบ่งดาเมจเป็นหลายครั้ง ผลติดตัวทอยทุกครั้ง | SW multi-hit |
| **พลังตามกาย** ใหม่ | scale: 'hp'/'def'/'spd' | ดาเมจคิดจาก HP สูงสุด / DEF / SPD ของผู้ใช้ด้วย (แทงก์ตีแรงได้) | SW stat-scaling |
| **ประหาร** ใหม่ | execute | เป้าหมาย HP ต่ำกว่าครึ่ง ดาเมจ +X | Dota/SW |
| **สายฟ้ากระโดด** ใหม่ | chain | ตีเป้าหลักแล้วกระโดดไปตัวอื่น ×0.7 ต่อทอด | Dota (chain) |

## D. พาสซีฟ (PassiveKind) — ใช้ได้ทั้ง "พาสซีฟประจำตัว" และ "พาสซีฟร่างหายาก"
| ชื่อในเกม (ตัวอย่าง) | kind | ผล | แนวคิดจาก |
|---|---|---|---|
| สวนกลับ | counter | โดนตี X% สวนด้วยสกิล 1 | SW auto-counter |
| สะท้อน | thorns | สะท้อนดาเมจ X% | Dota/SW |
| รอดตาย 1 ครั้ง | endure | รอด HP 1 + โล่ | SW |
| โคมนำวิญญาณ | revive | เพื่อนตัวแรกที่ล้ม ฟื้น | SW |
| ได้เทิร์นเมื่อฆ่า | killTurn | | SW |
| เกจเริ่ม / โล่เริ่ม | startAtb / startShield | | SW |
| ลดดาเมจตอนเลือดเกินครึ่ง | guard | | SW |
| คำสาปเมื่อโดนตี | curseOnHit | | SW |
| ฮีลทุกเทิร์น · ฮีลเกินเป็นโล่ · ฮีลล้างสถานะ | turnHeal / overheal / healCleanse | | SW |
| ลดเกจทุกครั้งที่ตี · ตีติดสถานะได้เกจ · คริติดสถานะ · ยืดสถานะ · ตายแล้วให้ของ | hitAtbDrain / hitStatusAtb / critDebuff / debuffExtend / deathGift | | SW |
| **ทุบสะท้าน** ใหม่ | bash (chance) | ตีโดน X% มึน 1 เทิร์น | Dota bash |
| **ร่างเงาลม** ใหม่ | evade (chance) | หลบการตีเดี่ยว X% | Dota evasion |
| **เกิดใหม่จากเถ้า** ใหม่ | rebirth (value) | ล้มแล้วฟื้นเองครั้งเดียว HP X% | ตำนานฟีนิกซ์ / SW |
| **จังหวะทอง** ใหม่ | critTurn (chance) | คริแล้ว X% ได้เทิร์นต่อ | SW |
| **ไฟอุ่นใจ** ใหม่ | allyEndure | เพื่อนตัวแรกที่จะตาย รอด HP 1 (ครั้งเดียว) | Dota (กันตายให้เพื่อน) |
