## 1. วิสัยทัศน์

ประโยคขาย: **"ไข่จักรวาลแตก ตำนานทุกชาติหลุดมาอยู่ในโลกเดียว — ฟัก ผูกพัน และสร้างทีมในตำนานของคุณ"**

เรื่องย่อ: ไข่จักรวาลที่กักตำนานของทุกภพไว้ได้แตกออก สัตว์และอสูรจากทุกวัฒนธรรมกระจายมาอยู่ในโลกเดียวกัน ผู้เล่นคือผู้พันธสัญญาที่ตามเก็บไข่ ฟัก และผูกพันกับพวกมัน เพื่อตามหาเศษไข่จักรวาลก่อนที่ภพต่างๆ จะพังทับกัน

เสาหลัก 5 ข้อ
1. **ภาพและเอฟเฟ็คอลังการ** — ทุกสกิลต้องดูดี ฉากสกิลสุดยอดมีตัดภาพ ★5 เปลี่ยนเอฟเฟ็คสกิลจริง
2. **ทุกการต่อสู้มีโอกาสได้ไข่** — ไข่ป่า เศษไข่ การ์ด ดรอปจากทุกด่าน
3. **จัดทีมลึก** — ธาตุ ปฏิกิริยาธาตุ สถานะแบบ RO สเตตัสที่ลงเอง สายวิวัฒน์
4. **แฟร์** — มอนทุกตัวฟาร์มได้ ของสุ่มเร่งเวลาได้ แต่พลังสูงสุดเท่ากัน
5. **เล่นได้ทั้งตั้งใจและเปิด AUTO** — เอฟเฟ็คดูดีแม้เร่ง x3 และข้ามฉากสกิลสุดยอดได้

## 2. วงจรการเล่น

```
แผนที่โลก → เลือกด่าน → จัดทีม 4 ตัว → ต่อสู้ 3 เวฟ (เวฟ 3 อาจเป็นบอส)
→ รางวัล (ทอง EXP เศษไข่ ไข่ป่า การ์ด อุปกรณ์) → ฟักไข่ / อัปเลเวล / ลงสเตตัส / ใส่อุปกรณ์
→ ด่านต่อไป / ดันเจี้ยน / อารีน่า
```
วงจรรายวัน: ด่านรายวัน (ไข่ธาตุตามวัน) → ดันอุปกรณ์ → อารีน่า 5 ครั้ง → ส่งมอนในคลังไปสำรวจ (ได้ของตอนออฟไลน์) → บอส MVP ตามรอบ

## 3. ระบบต่อสู้

### 3.1 โครงหลัก
- ทีม 4 ต่อสูงสุด 4 (บอสบางตัวเป็นตัวเดียวหรือหลายชิ้นส่วน)
- **เกจเทิร์น (ATB):** ทุกตัวเติมเกจตาม SPD ใครถึง 100 ก่อนได้เล่นก่อน แสดงลำดับเทิร์นด้านบนจอ
- มอนมี **สกิล 3 ช่อง** (S1 ตีปกติ, S2 มีคูลดาวน์, S3 สกิลสุดยอด) + **พาสซีฟ 1 ช่อง** (ปลดที่สายวิวัฒน์)
- **สกิลผู้นำ:** มอนตัวแรกในทีมให้โบนัสทั้งทีม เช่น "SPD ทีม +15%" หรือ "ATK ธาตุไฟ +20%"
- **AUTO, ความเร็ว x1/x2/x3, ข้ามฉากสกิลสุดยอด** มีตั้งแต่ P0
- สกิลสุดยอดมี **ฉากตัดภาพ** (ภาพมอน + ชื่อสกิล + สีธาตุ) และกล้องซูม

### 3.2 ธาตุ (6 ธาตุ)
- วงจร: **ไฟ > ลม > ดิน > น้ำ > ไฟ** ได้เปรียบ ×1.3 · เสียเปรียบ ×0.85
- **แสง ⇄ มืด** ตีกันได้เปรียบ ×1.3 ทั้งสองทาง
- ตำนานกับธาตุ: ฟีนิกซ์/หงส์ชาด = ไฟ · มังกรคราม/กริฟฟิน/ครุฑ = ลม · นาค/คราเคน/เงือก = น้ำ · ควายธนู/เต่าดำ/โกเลม = ดิน · กิเลน/ยูนิคอร์น/วาลคีรี = แสง · เสือสมิง/อนูบิส/เถาเที่ย = มืด

### 3.3 ปฏิกิริยาธาตุ (จุดขายหลัก)
สกิลบางสกิลติด **เครื่องหมายธาตุ** บนเป้าหมาย (อยู่ 2 เทิร์น) ถ้าโดนตีด้วยอีกธาตุจะเกิดปฏิกิริยาและเครื่องหมายหายไป

| เครื่องหมาย + ธาตุที่ตีซ้ำ | ปฏิกิริยา | ผล | เอฟเฟ็ค |
|---|---|---|---|
| เปียก + ลม | **พายุฟ้าคะนอง** | ฟ้าผ่ากระโดดไป 3 ตัว + SPD ลด | สายฟ้าโยงระหว่างศัตรู |
| เปียก + ไฟ | **ไอน้ำ** | ตาบอด 2 เทิร์น | ไอน้ำพวยพุ่ง |
| ไฟ + ลม | **ไฟลาม** | เผาไหม้ทั้งทีมศัตรู | วงไฟวิ่งรอบสนาม |
| ดิน + น้ำ | **โคลนดูด** | เกจลด 30% | โคลนดูดขา |
| ดิน + ไฟ | **ลาวา** | DEF แตก + เผาไหม้ | พื้นแตกลาวาปะทุ |
| แสง + มืด | **สุริยคราส** | ดาเมจทะลุ DEF ก้อนใหญ่ | จอมืดแล้ววงแสงระเบิด |
| เปียก + แช่แข็ง → ดิน | **ทุบน้ำแข็ง** | ดาเมจ ×2 ใส่ตัวที่แช่แข็ง | น้ำแข็งแตกกระจาย |

กฎ: เกิดได้ครั้งเดียวต่อเครื่องหมาย บอสมีค่าต้านทานสถานะ แต่โดนปฏิกิริยาได้ปกติ

### 3.4 สถานะแบบ RO
ลบ: เผาไหม้ · พิษ · แช่แข็ง (ข้ามเทิร์น) · กลายเป็นหิน (ข้ามเทิร์น DEF ขึ้น) · หลับ (ตื่นเมื่อโดนตี) · มึน · เงียบ (ใช้ได้แค่ S1) · ตาบอด (ตีพลาด 50%) · ลดฮีล · ลด ATK/DEF/SPD · ลดเกจ
บวก: เพิ่ม ATK/DEF/SPD/คริ · โล่ · ฟื้นฟูต่อเนื่อง · อมตะ · ภูมิคุ้มกัน · สะท้อนดาเมจ · ยั่วยุ (ของฝั่งเรา)
โอกาสติดสถานะ = โอกาสสกิล × (1 + INT ผู้ตี) − ค่าต้านทาน (LUK ผู้โดน) มีขั้นต่ำ 15% ยกเว้นบอส

### 3.5 Perfect Timing
ตอนกดสกิลสุดยอดด้วยมือ จะมีวงหดเข้าหาจุดกลาง แตะตรงจังหวะได้ **+15%** ดาเมจหรือฮีล ถ้าเปิด AUTO ได้ผลปกติ ไม่มีบทลงโทษ

### 3.6 สกิลคู่ (Duo Burst)
คู่มอนที่มีตำนานเกี่ยวข้องกัน เมื่ออยู่ทีมเดียวกันและ Bond ≥ 5 ทั้งคู่ จะได้ปุ่มสกิลคู่ (ใช้ได้ 1 ครั้งต่อการต่อสู้) ฉากตัดภาพ 2 ตัว
ตัวอย่าง: มังกรคราม + พยัคฆ์ขาว · ครุฑน้อย + พญานาคมณี (คู่ปรับ) · ฟีนิกซ์ + หงส์ชาด · กระต่ายหยก + จู๋หลง · เมดูซ่า + ไฮดรา

### 3.7 สูตรดาเมจตั้งต้น
`Damage = SkillMult × ATK × 3 × 100/(100 + DEF×(1−DefBreak)) × Element × Crit × Reaction × rand(0.92–1.08)`
คริ ×1.5 + (DEX×0.2%) · Heal = HealMult × MaxHP ของผู้ฮีล หรือ ATK ตามสกิล · ทุกบัฟลดมีเพดานในไฟล์ config

### 3.8 ระบบต่อสู้ต้องเป็น deterministic
ระบบต่อสู้เขียนเป็นโมดูลกลางตัวเดียวที่ใช้ทั้งในเครื่องผู้เล่นและบนเซิร์ฟเวอร์ ถ้าเริ่มจากเลขสุ่ม (seed) เดียวกันและกดปุ่มเหมือนกัน ผลต้องออกมาเหมือนกันทุกครั้ง เครื่องผู้เล่นส่งบันทึกการกด + seed ขึ้นไป เซิร์ฟเวอร์จำลองการต่อสู้ซ้ำเพื่อตรวจก่อนให้รางวัล ใช้กันโกงทั้ง PvE และ PvP

## 4. มอน

### 4.1 ค่าหลัก
- ความหายากโดยกำเนิด: **Common / Rare / Epic / Legendary** (ไม่ใช่ตัวคูณพลังมหาศาล แต่ต่างกันที่ความซับซ้อนของกลไกและงบค่าสเตตัส ≈ 100/110/120/130%)
- **ดาวเติบโต ★1–★5** ทุกความหายากขึ้นถึง ★5 ได้
- เลเวลสูงสุดตามดาว: ★1=20 · ★2=30 · ★3=40 · ★4=50 · ★5=60
- **Bond 1–10** ขึ้นจากการใช้งานและให้ของ ปลดเรื่องราว สกิลคู่ และท่าพักพิเศษ

### 4.2 อัปสเตตัสเอง (จาก RO)
ทุกเลเวลได้ **3 แต้ม** ลงใน 6 ค่า

| ค่า | ผล |
|---|---|
| STR | ATK |
| AGI | SPD (เกจเทิร์น) + หลบหลีก |
| VIT | HP + DEF |
| INT | พลังสกิล + โอกาสติดสถานะ |
| DEX | ความแม่น + ดาเมจคริ |
| LUK | อัตราคริ + ต้านสถานะ |

มีชุดแนะนำให้กดอัตโนมัติ · รีเซ็ตได้ด้วย "ผลไม้ลืมตน" (ฟาร์มได้/ขายในร้าน)

### 4.3 สายวิวัฒน์ (แทนการเปลี่ยนอาชีพของ RO)
ถึง ★3 เลือก **สาย A หรือ B** เปลี่ยน S2 + ปลดพาสซีฟ + โทนสีออร่า/เอฟเฟ็ค (ไม่ต้องวาดภาพใหม่)
ตัวอย่าง จิ้งจอกเพลิงอรุณ: **นักล่าเปลวไฟ** (คริ ตีเดี่ยวแรง) / **ผู้พิทักษ์อรุณ** (โล่ไฟ ยั่วยุ) · เปลี่ยนสายได้ด้วยไอเทม

### 4.4 ★5 สกิลวิวัฒน์
ที่ ★5 สกิลสุดยอด **เปลี่ยนเอฟเฟ็ค** ไม่ใช่แค่แรงขึ้น เช่น ลูกไฟ 3 ลูก → นกไฟ 3 ตัวโฉบ · คลื่นธรรมดา → คลื่นมังกรน้ำ

### 4.5 ออร่าตามดาว (ทำด้วยโค้ด ใช้ได้ทุกตัว)
★1 ไม่มี · ★2 วงแสงพื้น · ★3 ละอองธาตุ · ★4 ขอบเรืองแสง + เงาตามตัว · ★5 ออร่าเต็มตัว + ลูกแสงโคจร + วงเวทหมุน + ท่าพักพิเศษ

### 4.6 ไข่ป่า vs ไข่ดารา
| | ไข่ป่า (ฟาร์ม) | ไข่ดารา (สุ่ม) |
|---|---|---|
| ค่าอัพดาว/เลเวล | ถูกกว่า ~40% | ปกติ |
| Bond | ขึ้นเร็วกว่า | ปกติ |
| ช่อง Wild Trait | มี (สุ่มใหม่ได้ด้วยของฟาร์ม) | ไม่มี |
| ผสมพันธุ์ / ขายไข่ในตลาด | ได้ | ไม่ได้ |
| หน้าตา | ปกติ | **ร่าง Starborn** สีพิเศษ ออร่าตั้งแต่ ★1 ฉากฟักเฉพาะ |
| สกิล | ปกติ | **รูปแบบสกิลต่าง** (แรงเท่ากันแต่เล่นต่าง) |
| ดาวเริ่ม | ★1 | ★2 |
พลังสูงสุดเท่ากัน

### 4.7 ตัวซ้ำ
ใช้เป็นวัตถุดิบอัพดาว / ปล่อยรับ Essence / แปลงเป็นการ์ด (ถ้าเป็นไข่ป่า) · ห้ามกินตัวที่ล็อก ตัวผู้นำ และตัวที่อยู่ในทีมป้องกัน

## 5. อุปกรณ์มอน + การ์ด

### 5.1 อุปกรณ์ 4 ช่อง
หัว · คอ · เครื่องราง (**มองเห็นลอยข้างตัว**) · แกนพลัง
- ค่าหลัก 1 + ค่ารอง 2–4 · เกรด ขาว / เขียว / ฟ้า / ม่วง / ทอง / รุ้ง
- **เซ็ต 2/4 ชิ้น** เช่น เซ็ตเพลิง (ตีติดเผาไหม้), เซ็ตวายุ (SPD +20%), เซ็ตพิทักษ์ (โล่เริ่มต้น), เซ็ตสายฟ้า (ปฏิกิริยาแรงขึ้น 25%), เซ็ตคืนชีพ (ฟื้นครั้งเดียว 30%)
- เซ็ตครบ 4 ชิ้นมี **เอฟเฟ็คบนตัว** เช่น รอยเท้าไฟ ประกายลม
- **ตีบวก +0 ถึง +15:** +1 ถึง +9 สำเร็จแน่นอน · +10 ขึ้นไปมีโอกาสพลาด · พลาดที่ +12 ขึ้นไปจะลดลง 1 ขั้น เว้นแต่ใช้ "ผงกันลดขั้น" · **ไม่มีของแตก**
- หัวกับคอแสดงเป็นไอคอน ไม่วาดบนตัว (ดูเหตุผลใน ART_STYLE_GUIDE) · มีระบบเปลี่ยนรูปลักษณ์ (Transmog) สำหรับเครื่องราง

### 5.2 การ์ดมอน (จาก RO)
- มอนทุกสายพันธุ์ดรอป **การ์ดของตัวเอง** · ด่านทั่วไป 0.5% · บอส 2% · บอส MVP เฉพาะอันดับต้นๆ
- เสียบในอุปกรณ์ที่มีช่อง (0–2 ช่องตามเกรด) ถอดได้ด้วยไอเทม
- ประเภทผล: ดาเมจต่อธาตุ · ต้านธาตุ · โอกาสติดสถานะ · ต้านสถานะ · ดูดเลือด · เพิ่มเกจเริ่มต้น · ความสามารถเฉพาะ (การ์ด MVP)
- **ซื้อขายในตลาดได้** · มี "อัลบั้มการ์ด" สะสมให้โบนัสเล็กน้อยเป็นของแต่ง

## 6. ไข่และการฟัก
แหล่งไข่: ดรอปจากด่าน (personal roll) · เศษไข่สะสมจนประกอบได้ (การันตี) · ด่านรายวันตามธาตุ · บอส · ผสมพันธุ์ · ตลาด (ไข่ป่าที่ยังไม่ฟัก) · ไข่ดารา (สุ่ม แสดงอัตรา + การันตี)

| ความหายาก | โอกาสดรอปต่อการผ่านด่าน | เศษต่อการผ่าน | เศษที่ต้องใช้ | เวลาฟัก |
|---|---|---|---|---|
| Common | 8% | 1 | 20 | 30 วิ |
| Rare | 3% | 1 | 40 | 5 นาที |
| Epic | 1% | 1 (ด่านยาก) | 80 | 30 นาที |
| Legendary | บอสเท่านั้น 0.5–1% | 1–2 (บอส) | 120 | 2 ชม. |
- ช่องฟัก 3 ช่องเริ่มต้น เพิ่มได้ถึง 6 ช่อง · เวลาฟักเดินต่อตอนออฟไลน์ · เร่งได้ด้วยดูโฆษณา/คริสตัล
- ฉากฟัก: สั่น → ร้าว 3 ขั้น → ลำแสง → ระเบิด → เงา → เปิดตัว (ทำแล้วในฉากทดสอบ)
- ผสมพันธุ์ (Early Access): พ่อแม่ Lv.30+ Bond 4+ เห็นรายการผลลัพธ์และโอกาสก่อนกด ไม่เสียพ่อแม่

### 7.2 ดันเจี้ยน
- **ดันอุปกรณ์** "ถ้ำผลึก" ชั้น 1–10 เลือกฟาร์มเซ็ตได้ (แบบดัน Rune ของ SW)

- **ดันบอส "สุสานจันทรา"** บอส **ออสซาร์ค ราชันกระดูก** (รายละเอียด §8)
- **หอคอยไข่จักรวาล** 100 ชั้น รีเซ็ตรายเดือน

### 7.3 บอส MVP บอสโลก
**โกรุมัก ยักษ์บรรพกาลแห่งหลุม** (รายละเอียด §8) เกิดทุก 4 ชม. ทั้งเซิร์ฟตีเลือดก้อนเดียว คนละ 3 ครั้งต่อรอบ จัดอันดับดาเมจ

### 7.4 สำรวจ (ออฟไลน์)
ส่งมอนที่ไม่ได้ใช้ไปสำรวจภพที่ผ่านแล้ว 1–8 ชม. ได้เศษไข่ ทอง วัสดุ (สร้างนิสัยกลับมาเก็บของ)

## 8. บอสเด่น (ชื่อและดีไซน์ของเราเอง)

### 8.1 ออสซาร์ค ราชันกระดูก — *Ossarch, the Bone Sovereign* (ได้แรงบันดาลใจจากบอสราชาโครงกระดูก)
- **หน้าตา:** ราชาโครงกระดูกตัวใหญ่ มงกุฎสำริดโบราณร้าว ผ้าคลุมทำจากธงพิธีขาดวิ่น ไฟวิญญาณ**สีฟ้าม่วง**ในเบ้าตาและซี่โครง ถือ**คทาหัวระฆัง** (ไม่ใช้ดาบ ไม่ใช้ไฟเขียว เพื่อไม่ให้เหมือนของเกมอื่น)
- **ร่าง 1:** ระฆังวิญญาณ (มึน 1 ตัว) · ปลุกทหารกระดูก (เรียกลูกน้อง 2 ตัว) · ดูดวิญญาณ (ตีแล้วฟื้น HP)
- **ร่าง 2 "กระดูกแตก":** HP หมดครั้งแรก ร่างแตกเป็น **4 ชิ้น** (กะโหลก แขน ซี่โครง ขา) เป็นเป้าแยก ต้องทำลายให้ครบใน **3 เทิร์น** ไม่งั้นรวมร่างฟื้นเต็ม → ต้องใช้สกิลตีหมู่หรือปฏิกิริยาไฟลาม
- **ดรอป:** การ์ดราชันกระดูก (ตายครั้งแรกฟื้น 20% HP) · ไข่ "อัศวินกระดูก" · ชิ้นส่วนเซ็ตคืนชีพ

### 8.2 โกรุมัก ยักษ์บรรพกาลแห่งหลุม — *Gorrumak, the Pit Colossus* (ได้แรงบันดาลใจจากบอสใหญ่กลางแมพ)
- **หน้าตา:** ยักษ์หินกึ่งลิงกึ่งหมูป่า ตัวคลุมมอส หลังมีหนามผลึก **กลางอกฝังผลึกรูปไข่เรืองแสง** (ผูกกับธีมไข่จักรวาล) เขี้ยวงอนสองข้าง นั่งในหลุมผลึก
- **กลไก:** เกิดทุก 4 ชม. · ล้มแต่ละครั้ง **เลเวล +1** (แรงขึ้นเรื่อยๆ ทั้งเซิร์ฟ) · กระทืบแผ่นดิน (ทั้งทีม + มึน) · ผลึกสะท้อน · ตะกละ (กินบัฟผู้เล่นแล้วฟื้น HP) · โกรธา (HP < 30% ATK/SPD ขึ้น)
- **ดรอป:** ทุกคนที่ร่วมตีได้ **"ผลอมตะ"** (มอน 1 ตัวฟื้นชีพครั้งเดียวในด่านถัดไป) · อันดับ MVP ได้การ์ด MVP โกรุมัก · เซิร์ฟล้มครบ 3 ครั้งต่อวัน ทุกคนได้ลุ้น "ไข่ผลึกโกรุมัก" (ร่างลูกน่ารัก)

บอสทั้งหมด 16 ตัวอยู่ใน `BOSS_ROSTER_v2.csv`

## 9. PvP และกิลด์
- **อารีน่า:** ตั้งทีมป้องกัน 4 ตัว (AI คุม) · ตีวันละ 5 ครั้ง (+ตั๋วฟาร์มได้) · ลีกรายสัปดาห์ · ค่าปรับสมดุลแยกจาก PvE

## 10. เศรษฐกิจ
- สกุลเงิน: **ทอง** (ทุกอย่าง) · **คริสตัล** (พรีเมียม หาได้ในเกมนิดหน่อย) · Essence ตามธาตุ · เศษไข่ตามสายพันธุ์ · วัสดุอุปกรณ์ · เหรียญอารีน่า/กิลด์

## 12. งานภาพ (สรุป — รายละเอียดใน ART_STYLE_GUIDE.md)
- มอน: **5 ท่า × 2 มุม** (ยืน ตี ร่าย โดนตี Burst · หันหน้า/หันหลัง) + ไข่ 1 ภาพ = **11 ภาพต่อสายพันธุ์** (+ ท่าชนะเป็นตัวเลือก)
- บอส: **4 ท่า มุมเดียว** (ยืน ตี สกิลใหญ่ ตาย) + ชิ้นส่วนแยกสำหรับบอสหลายชิ้น
- ฝั่งศัตรูใช้ภาพมอนตัวเดียวกันกลับซ้ายขวา
- เอฟเฟ็ค ออร่า ฉากฟัก ปฏิกิริยาธาตุ = **โค้ดทั้งหมด**
- ฉากต่อสู้: ฉากพื้นหลังต่อภพ 1–2 ภาพ (ChatGPT วาด) + ของตกแต่งแยกชิ้น
- งานรวมถึง 1.0: 72 × 11 + 16 บอส × ~5 + ฉาก 16 + ไอคอน ≈ **1,000 ภาพ**

## 13. เทคนิค
- **Client:** TypeScript + PixiJS (WebGL) · PWA ติดตั้งได้ · แนวตั้งเป็นหลัก รองรับแนวนอน · ห่อด้วย Capacitor ลง Android ช่วง EA
- **Battle core:** โมดูล TypeScript ล้วน ไม่ผูกกับภาพ · deterministic (seeded RNG) · ใช้ร่วม client/server · ส่วนภาพอ่าน "event log" จาก battle core มาเล่นแอนิเมชัน
- **Server (ตั้งแต่ P2):** Node.js + PostgreSQL · REST/WebSocket เฉพาะ MVP/WoE · ตรวจ replay ก่อนให้รางวัล · ledger ทุกรายการของ/เงิน · idempotency ทุก claim
- **Hosting:** VPS + Docker Compose · ยังไม่มีเซิร์ฟเวอร์เรียลไทม์ ค่าใช้จ่ายต่ำ
- **คุณภาพกราฟิก ต่ำ/กลาง/สูง:** ลดจำนวนอนุภาค ปิด bloom บนเครื่องรุ่นถูก

## 15. กฎลิขสิทธิ์ของโปรเจกต์

4. ทุกคำสั่งวาดภาพต้องมีบรรทัด "original design, do not copy any existing game/film character"
5. ก่อนเปิดตัวจริง ให้ทนายตรวจชื่อเกม ชื่อมอน และโลโก้
