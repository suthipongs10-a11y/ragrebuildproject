# Eggbound — Art Style Guide (สำหรับ ChatGPT / ผู้สร้างภาพ)

ใช้คู่มือนี้ทุกครั้งที่สั่งวาดมอน บอส ไข่ หรือฉาก วางส่วน **MASTER STYLE BLOCK** ไว้บนสุดของทุกคำสั่ง

## 1. MASTER STYLE BLOCK (copy ทั้งก้อน)
```
STYLE: painterly anime fantasy game art for a 2.5D turn-based monster RPG.
Soft dimensional shading, clean readable silhouette, crisp edges, no blur.
Cute-but-cool proportions: slightly big head, expressive eyes, strong pose.
Lighting: warm key light from TOP-LEFT, soft cool fill from right.
Camera: HIGH ANGLE about 55 degrees looking down, orthographic feel.
Background: FULLY TRANSPARENT (or flat solid #FF00FF if transparency fails).
FORBIDDEN: ground, cast shadow, glow, aura, fire/particles/sparks, motion lines,
text, watermark, frame, second character.
ORIGINAL DESIGN — do not copy or resemble any existing game, film, anime
or novel character (Dota, League of Legends, Summoners War, Pokemon, etc.).
Base the creature on the public-domain myth only.
```

## 2. มุมมอง
- **FRONT VIEW** = 3/4 หันหน้า กล้องสูง 55° ตัวหันไป**ขวาล่าง** (ใช้เป็นฝั่งศัตรูโดยกลับซ้ายขวา)
- **BACK VIEW** = 3/4 หันหลัง กล้องสูงเท่าเดิม ตัวหันไป**ขวาบน** (ใช้เป็นฝั่งผู้เล่น)

## 3. ชุดภาพต่อมอน 1 สายพันธุ์ (11 ภาพ)
| # | ไฟล์ | เนื้อหา |
|---|---|---|
| 01 | `{id}_master.png` | ภาพต้นแบบ FRONT ท่ายืน (ต้องได้ OK ก่อนทำต่อ) |
| 02–06 | `{id}_front_{idle,attack,cast,hit,burst}.png` | 5 ท่าหันหน้า |
| 07–11 | `{id}_back_{idle,attack,cast,hit,burst}.png` | 5 ท่าหันหลัง |
| 12 | `egg{num}.png` | ไข่ประจำสายพันธุ์ ลวดลายตามตัว |
| (เลือก) | `{id}_front_victory.png` | ท่าชนะ |

ความหมายท่า: **idle** ยืนพัก · **attack** พุ่งโจมตี · **cast** ร่าย/คำราม/ยกตัว · **hit** สะดุ้งถอยหลัง หลับตา · **burst** ท่าเท่สุด เตรียมใช้สกิลสุดยอด
สำหรับมอนบิน: ทุกท่าลอยตัว ให้ปลายเท้า/หางล่างสุดอยู่ที่เส้นพื้นเหมือนเดิม (โค้ดจะเพิ่มการลอยให้เอง)

## 4. ข้อกำหนดทางเทคนิค (บังคับ)
- PNG 1024×1024 · ตัวอยู่กลางภาพ · เว้นขอบทุกด้าน ≥ 80px
- **เท้า/จุดต่ำสุดอยู่ที่ y ≈ 870px** (85% ของความสูง) ทุกภาพ
- **ขนาดตัวเท่ากันทุกภาพ** ในชุดเดียวกัน · ความสูงตัวประมาณ 60–70% ของภาพ
- ทุกภาพหลังภาพต้นแบบต้องแนบภาพต้นแบบเป็น reference และขึ้นต้นด้วย:
  `Using the attached reference as the EXACT same character (same design, colors, markings, proportions, scale, line style and lighting):`

## 5. ขนาดตามความหายาก/ประเภท
| ประเภท | ความสูงตัวในภาพ | หมายเหตุ |
|---|---|---|
| Common | 55–60% | ตัวเล็ก น่ารัก |
| Rare / Epic | 60–68% | รายละเอียดมากขึ้น เครื่องประดับเฉพาะตัว |
| Legendary | 68–72% | ท่าทางสง่า มีองค์ประกอบพิเศษ (มงกุฎ ปีก ลวดลายทอง) |
| บอส | ดูข้อ 7 | |

## 6. โทนสีตามธาตุ (ใช้เป็นสีเน้น ไม่ต้องทั้งตัว)
ไฟ ส้ม-แดง · น้ำ ฟ้า-น้ำเงิน · ลม เขียวมิ้นต์ · ดิน น้ำตาล-เขียวมอส · แสง ทอง-ขาวครีม · มืด ม่วง-น้ำเงินเข้ม

## 7. บอส
- **4 ท่า มุม FRONT อย่างเดียว:** `{boss}_idle / attack / skill / death`
- ภาพ 1536×1536 · ตัวเต็มภาพ 80% · เท้าที่ y ≈ 85%
- บอสหลายชิ้น (ออสซาร์คร่าง 2, คราเคน, อนันตนาคราช, โอโรจิ, เต่าดำ): วาด**ตัวหลัก**กับ**ชิ้นส่วนแยก**เป็นคนละไฟล์ เช่น `boss02_part_skull.png`
- บอสที่ได้แรงบันดาลใจจากเกมอื่น ต้องทำตามคำอธิบายใน `BOSS_ROSTER_v2.csv` เท่านั้น (สี อาวุธ รูปร่างที่กำหนดไว้เพื่อให้ต่างจากต้นฉบับ)

## 8. อุปกรณ์และสกิน
- **เครื่องราง** (ลอยข้างตัว): วาดเดี่ยว 1 ภาพ ขนาด 30% ของภาพ
- **หัว/คอ ไม่ต้องวาดบนตัว** แสดงเป็นไอคอนในหน้าข้อมูล (ไอคอน 512×512 มุมตรง)
- **สกิน:** วาดมอนสวมชุดมาในภาพเลยทั้ง 11 ภาพ ใช้ภาพต้นแบบเดิมเป็น reference + คำอธิบายชุด

## 9. ฉากต่อสู้ต่อภพ
- 1 ภาพพื้นหลัง 2048×1536 มุมสูง 55° ไม่มีตัวละคร พื้นที่กลางภาพโล่งเป็นลานต่อสู้
- ของตกแต่งแยกชิ้น (ต้นไม้ หิน โคม เสา) พื้นหลังโปร่งใส 6–10 ชิ้นต่อภพ
- ลายเซ็นภพ: ทุ่งไข่ป่วน (ทุ่งหญ้า ไข่ยักษ์) · สุวรรณภูมิ (ป่าดิบ ศาลเจ้า ผ้าแพร) · สวรรค์บูรพา (ภูเขาหมอก ศาลาแดง) · ซานไห่ (หินประหลาด ต้นไม้ยักษ์) · แดนเหนือ (ซากวิหารหินอ่อน หิมะ) · ทะเลลึก (ปะการังเรืองแสง) · ทะเลทราย (เสาหิน ทรายทอง) · เกาะอสูร (โทริอิ ซากุระ หมอก)

## 10. ตรวจก่อนส่ง (ทุกชุด)
- [ ] หน้าตา สี ลาย ตรงกับภาพต้นแบบทุกภาพ
- [ ] ขนาดเท่ากัน เท้าที่ ~85% ของภาพ
- [ ] ทิศถูก (FRONT ขวาล่าง / BACK ขวาบน)
- [ ] ไม่มีเงา พื้น แสงเรือง ไฟ อนุภาค ตัวหนังสือ
- [ ] พื้นหลังโปร่งใสทั้งภาพ (หรือ #FF00FF ทั้งภาพ)
- [ ] ไม่คล้ายตัวละครจากเกม/หนังที่มีลิขสิทธิ์
- [ ] zip ชื่อ `EGGBOUND_{id}_SET.zip` + `notes.txt`
