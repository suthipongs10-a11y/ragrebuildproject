# Implementation Brief — P0 Battle Core

อ่าน `GAME_BLUEPRINT_v2_TH.md`, `GAME_CONFIG_v2.json`, `MONSTER_ROSTER_v2.json` ก่อนเริ่ม

## เป้าหมาย
พิสูจน์ว่าการต่อสู้เทิร์นเบส + เอฟเฟ็ค + ปฏิกิริยาธาตุ **สนุกพอให้เล่นซ้ำ** ก่อนลงทุนภาพและเซิร์ฟเวอร์

## ขอบเขต
1. **หน้าแผนที่:** ภพ "ทุ่งไข่ป่วน" 3 ด่าน (ด่าน 3 มีบอสอสูรรากไม้ยักษ์ใช้ภาพเปลี่ยนสีชั่วคราว) · ดาว 1–3 ต่อด่าน
2. **จัดทีม:** เลือก 4 จาก 6 ตัวเริ่มต้น (MON_A01–A06) · เลือกผู้นำ
3. **ต่อสู้:** 4v4 · ATB + แถบลำดับเทิร์น · S1/S2/S3 · สกิลผู้นำ · เครื่องหมายธาตุ + ปฏิกิริยา **ไฟลาม · พายุฟ้าคะนอง · ไอน้ำ** · สถานะ **เผาไหม้ เปียก มึน หลับ ลด DEF เพิ่ม ATK** · ฉากตัดภาพ · Perfect Timing · AUTO · x1/x2/x3 · ข้ามฉากสกิลสุดยอด · ฉากชนะ/แพ้
4. **หลังต่อสู้:** หน้ารางวัล (ทอง EXP เศษไข่ ไข่ป่า) · หน้าฟักไข่ (นำฉากจาก Test Lab มาใช้)
5. **มอน:** เลเวล + ดาว + ออร่า ★1–★5 · หน้าข้อมูลมอน (ค่าสเตตัส สกิล)
6. **เซฟ:** localStorage ห่อ try/catch · แยกเป็น `SaveService` เพื่อเปลี่ยนเป็นเซิร์ฟเวอร์ใน P2
7. **ตั้งค่า:** เสียง · คุณภาพกราฟิก · ข้ามฉากสกิลสุดยอด

## สถาปัตยกรรม (บังคับ)
- `battle-core/` TypeScript ล้วน ไม่แตะ DOM/canvas · input = ทีม + seed + คำสั่ง · output = **event log** (`turn_start`, `skill_used`, `damage`, `heal`, `status_apply`, `reaction`, `death`, `wave_clear` …)
- `render/` PixiJS อ่าน event log มาเล่นแอนิเมชันและเอฟเฟ็ค · เปลี่ยนความเร็วได้โดยไม่กระทบผลลัพธ์
- `vfx/` เอฟเฟ็คตามธาตุแบบ template: `slash`, `projectile_volley`, `dash_chain`, `wave`, `meteor`, `heal_bubbles`, `buff_pillar`, `orb`, `reaction_*` · รับ palette ธาตุเป็นพารามิเตอร์
- `data/` อ่านมอน สกิล ค่าตั้งต้นจาก JSON · ห้าม hardcode ตัวเลขในโค้ด
- unit test: battle-core ต้องให้ผลเหมือนกัน 100% เมื่อ seed + คำสั่งเหมือนกัน · ทดสอบจำลองสู้อัตโนมัติ 1,000 รอบเพื่อดูอัตราชนะ

## ภาพที่มี / ที่รอ
- พร้อม: MON_A01 จิ้งจอกเพลิงอรุณ (11 ภาพ + ไข่)
- รอ: MON_A02–A06 → ระหว่างรอใช้จิ้งจอกเปลี่ยนสีตามธาตุ และติดป้าย "ภาพชั่วคราว"

## เกณฑ์ผ่าน P0
- เล่นจบ 3 ด่านได้โดยไม่ค้าง ทั้งกดเองและ AUTO
- ปฏิกิริยาธาตุ 3 แบบเกิดได้จริงและมองออกว่าเกิดอะไร
- 60fps บนมือถือระดับกลางที่ระดับคุณภาพ "กลาง"
- ผล battle-core ตรงกันเมื่อรันซ้ำด้วย seed เดิม
- มีรายการ IMPLEMENTED / PLACEHOLDER / UNTESTED แยกชัด

## ห้าม
- ทำเซิร์ฟเวอร์ ระบบจ่ายเงิน หรือ gacha ใน P0
- ใช้ asset หรือชื่อจากเกมอื่น
