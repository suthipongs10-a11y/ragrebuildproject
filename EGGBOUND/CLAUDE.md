## 1. โปรเจกต์คืออะไร
เกมเก็บไข่-ฟักมอน แนวเทิร์นเบสสไตล์ Summoners War + ระบบจาก Ragnarok Online
- ไม่มีเดินในแมพ: แผนที่ภพ → แตะด่าน → สู้ 4v4 ทันที
- จุดขาย: ท่าทาง สกิล เอฟเฟ็คสวยอลังการ + **ปฏิกิริยาธาตุ** + ธีมตำนานรวม (ไทย + ตะวันตก + จีน/ญี่ปุ่น/กรีก/นอร์ส + เผ่าแปลก) ไม่ไทยจ๋า
- ออนไลน์แบบ async สไตล์ SW: เล่นคนเดียว เจอกันเฉพาะ PvP/อารีน่า/กิลด์วอ (WoE)/บอส MVP — **ทำ solo ให้ลงตัวก่อน**
- ภาษา UI/การคุยกับเจ้าของ: ไทย · ตอบสั้น ตรง แนะนำชัดเจน คุมต้นทุน

## 2. แบ่งงาน
- **Claude:** เขียนเกมทั้งหมด + VFX/ออร่า/ฟักไข่ด้วยโค้ด + เขียนไฟล์คำสั่งวาดภาพ (.txt) ให้ ChatGPT
- **ChatGPT:** วาดภาพทั้งหมดตาม `art/prompts/*.txt` เจ้าของเป็นคนส่งต่อ แล้วส่ง zip กลับมา · **ตั้งแต่ 2026-10-14 เจ้าของใช้ ChatGPT เป็นหลัก (สวยกว่า Google Flow มาก)** → เขียนไฟล์คำสั่งให้เหมาะกับ ChatGPT ก่อน (แนบ master/ภาพอ้างอิง · ทีละภาพ · ตรวจ #01 แล้วค่อย OK · ขอ PNG พื้นใส) ส่วน Flow เป็นทางสำรอง
- ภาพใหม่: ตรวจครบ/ชื่อไฟล์/โปร่งใส/ไฟล์เสีย(truncated) → `python3 -I game/tools/import_art.py <set_dir> <ID> <ความสูงpx> [--mirror pose,pose] [--key monXXe]` → ตั้ง `art:` ใน `SPECIES`
  - **ภาพจาก Google Flow:** ได้ JPG สัดส่วนตายตัว (1:1, 9:16, 16:9) ชื่อไฟล์สุ่ม → จับคู่ชื่อเอง แล้ว `python3 -I game/tools/fit_flow.py <in> <out.png> <W>x<H> pad|crop|squash|anchor [--bottom F] [--key] [--anchor CX,CY,RX]` ปรับให้ตรง canvas ในไฟล์คำสั่งก่อนนำเข้า (ฐานยืน BATCH16: วัดจุดกลาง+ครึ่งความกว้างผิวบนของฐานในภาพ แล้วใช้ `1024x512 anchor --key --anchor CX,CY,RX` ย้ายไปจุดมาตรฐาน `PED` 512,150,380 → `import_fx.py`) (`--key` = ลบพื้นชมพู #FF00FF ของภาพวัตถุ/ตัวละคร + กันขอบชมพู · ตัดเฉพาะพื้นชมพูที่ต่อจากขอบภาพ สีม่วง/ชมพูในตัววัตถุจึงไม่หาย) · Flow วาดขนาดตัวไม่คงที่ทุกท่า → เทียบกับ idle แล้วย่อท่าที่ใหญ่เกินรอบจุดเท้า · Flow มักแถมภาพอ้างอิงที่แนบไป (เช่น fx_burst/fx_rays) ห้ามนำเข้าทับ
  - ภาพของมอนที่ยังไม่มีในเกม → `import_art.py ... --out assets_staged` (ไม่ฝังใน build จนกว่าจะย้ายเข้า `assets/`)
  - ภาพทุกโฟลเดอร์ (`assets/` `assets_ext/` `assets_bg/`) ฝังใน build เป็น AVIF อัตโนมัติ (`tools/avif_cache.py`) — ไม่ต้องทำอะไรเพิ่ม แค่ดูขนาด build ไม่ให้เกิน ~15.5MB
  - **เช็กทิศก่อนใช้ `--mirror`:** ท่าหน้าต้องหันขวาล่างแบบจิ้งจอก (หัวอยู่ขวา หางอยู่ซ้าย) — B05 เคยถูกกลับด้านผิดจนหันซ้าย (แก้แล้ว) · ส่งซ่อมบางท่า: เอาชุดเดิม + ภาพใหม่มารวมแล้วรันซ้ำความสูงเดิม (วัดจาก front_idle ในเกม) ภาพขนาดต่างกัน (1254 vs 1024) ย่อให้เท่ากันก่อน
  - ตัวนำเข้ายึด "เท้าจริง" ของแต่ละภาพ (ChatGPT ไม่วางเท้าที่ y=870 ตามสั่ง) · ความสูง: ตัวเล็ก 270 / ปกติ 300–320 / ตัวใหญ่-มหากาพย์ 360 · ภาพเสียจะข้ามและเกมใช้ท่าสำรอง (`spr()` → idle มุมเดียวกัน → master)

## 3. การตัดสินใจที่ล็อกแล้ว (ห้ามเปลี่ยนเองโดยไม่ถาม)
- เทิร์นเบส ATB · 3 สกิล + สกิลผู้นำ · ตัวแรกในทีม = ผู้นำ
- **คลังกลไกสกิล (เจ้าของตัดสิน 2026-10-14): `docs/SKILL_CATALOG_TH.md`** — เอาแนวคิดกลไกจาก SW และ Dota มาได้ แต่ตั้งชื่อใหม่ของเรา และห้ามยกชุดสกิลของตัวไหนมาทั้งชุด · มอนตัวใหม่มี **พาสซีฟประจำตัว** (`SpeciesDef.passive`, ทุกร่าง แบบ SW) ได้อีก 1 อย่าง นอกจาก 3 สกิล + ผู้นำ · ร่างหายากยังได้พาสซีฟร่างหายากเป็นอันที่ 4 (unit มี `passives[]`, ครั้งเดียวต่อการต่อสู้เก็บใน `used[]`) · กลไกใหม่ใน battle core: สถานะ แช่แข็ง `freeze` (ข้ามเทิร์น โดนตีครั้งถัดไป +30% แล้วแตก) · สับสน `confuse` (50% ตีพวกเดียวกัน ไม่ทำให้ตาย) · สกิล ตีรัว `hits` · พลังตามกาย `scale` hp/def/spd · ประหาร `execute` · สายฟ้ากระโดด `chain` · ผล ร่วมรบ `assist` · กินฝันร้าย `dreamEat` · พาสซีฟ ทุบสะท้าน `bash` · ร่างเงาลม `evade` · เกิดใหม่จากเถ้า `rebirth` · จังหวะทอง `critTurn` · ไฟอุ่นใจ `allyEndure` · ออร่า `aura` · ดูดเลือด `leech` · มอนเดิมไม่แตะ ผลสู้เหมือนเดิมเป๊ะ (RNG ทอยเฉพาะเมื่อมีกลไกนั้น) · **สกิล 2–3 ห้ามซ้ำกันทุกอย่าง** `tests/mechanics.ts` ตรวจ (มีคู่เก่า 2 คู่ยกเว้นไว้) · ไฟล์ catalog มีแผนแจกกลไกเด่นให้มอนตัวใหม่ 18 ตัวแล้ว · **กระจายกลไกใหม่ (2026-10-14, เจ้าของ "เน้นร่างพิเศษ ธาตุพิเศษ และบอส"):** ร่างหายากแสง/มืดได้ สับสน/แช่แข็ง/ตีรัว/ร่วมรบ/กระโดด เพิ่มในสกิลเดิม · ตำนานดารา S01–S07 + ขุนสมิงขาว ได้พาสซีฟประจำตัว · บอสโซนได้พาสซีฟเฉพาะบอส `EnemyRef.bp` (คลั่ง `enrage` ทุกตัว + 1 อย่างตามธีม) แสดงในหน้าโซน · พาสซีฟใหม่ `hitStatus` `enrage` · ลด HP/ATK บอสให้อัตราชนะเท่าเดิม — รายละเอียด catalog ข้อ F · มอนชุดใหม่รอภาพก่อน
- ภาพ 2D key pose (5 ท่า × 2 มุม: front/back) + แอนิเมชันด้วยโค้ด · 4 ทิศได้จาก mirror · **ไม่ทำ frame-by-frame**
- **ยกระดับการเคลื่อนไหวให้ใกล้ SW (ตัดสินใจ 2026-10-12, ทำตัวต้นแบบจิ้งจอกก่อน):** ท่าเพิ่ม windup/strike/follow (โจมตี 3 จังหวะ), cast2, joy, down (BATCH13-A) — ท่าที่ไม่มีจะใช้ท่าเดิมแทน (`poseKey()`) · "ภาพมีชีวิต" ด้วยโค้ด `warpDraw()` (หายใจ/โน้มตัว/สปริงตามแรง/ระลอก) · ท่าสกิลเฉพาะตัว = เมธอด `sk_<skillId>` ใน battleView (ไม่มีจะใช้ท่ากลาง) · ตัวเลขดาเมจแบบ SW `dmgText()` · ประกายโดนตี `hitSpark()` · ผ่านต้นแบบแล้วค่อยทำตัวอื่น
- ออร่าดาว, VFX, ฟักไข่ = โค้ดล้วน ใช้ได้กับทุกตัว
- **ขนาดตัวในสนามตามดาว (เจ้าของแจ้ง 2026-10-14: เสือร่างตื่น ★5 ตัวเล็กกว่ามอน ★1):** `sizeK()` ใน assets.ts ใช้ใน battleView `makeView` · ดาว ★1 ×0.92 · ★2 ×0.95 · ★3 ×0.98 · ★4 ×1 · ★5 ×1.08 · ★6 ×1.12 (บอสไม่หดต่ำกว่าขนาดตัวเอง) · ปรับตามภาพอัตโนมัติ (วัดพื้นที่ภาพ front_idle เทียบจิ้งจอก): ภาพระดับหายาก/มหากาพย์/ตำนานที่วาดมาเล็ก ขยายให้ได้อย่างน้อย 0.93/1.15/1.22 เท่าของจิ้งจอก · **ร่างวิวัฒน์ต้องใหญ่กว่าร่างเดิม ≥1.3 เท่า และ ≥1.3 เท่าของจิ้งจอก** (เพดานขยาย ×1.3) — ตอนนี้ A02e ×1.21 · A06e ×1.23 · A04e/A05e ×1.12 · B05e ×1.07 · ธรรมดาตัวเล็กโดยดีไซน์ (กระต่ายหยก ลูกหัสดีลิงค์) ไม่ขยาย · `__eb.sizeK` ไว้เช็ก
- **สีตามดาว:** ★4 เปลี่ยนสี/★5 ร่างวิวัฒน์ แสดงเฉพาะตอนอัปดาวเกินดาวที่เกิดมา (`lookOf` เทียบ `natStars`) — ตัวตำนานเกิด ★4 ยังเห็นสีจริง
- **ดาวแบบ SW (ตัดสินใจ 2026-10-12):** ฟักออกมาดาวตามความหายาก ธรรมดา ★1 · หายาก ★2 · **มหากาพย์ ★4 · ตำนาน ★5 (เปลี่ยน 2026-10-13)** · **ร่างหายาก +1 ดาว** (`natStars(sid, rare)`) · โอกาสร่างหายากลดตามระดับ `RARE_FORM_MULT` ธรรมดา ×1 · หายาก ×0.8 · มหากาพย์ ×0.5 · ตำนาน ×0.25 (ตำนานร่างหายาก ★6 ≈ 1 ใน 30,000 ไข่ดรอป) · อัปได้ถึง ★6 ทุกตัว · ฟักได้สายพันธุ์ใหม่ครั้งแรก → ตราประทับ "NEW!" สีรุ้งมุมบนซ้าย (`newBadge()`) (ไข่ซ้ำ +1 ดาว) · ค่าใน `NAT_STARS`/`MAX_STARS` (data.ts) · ฉากฟักตัวหายากขึ้นไปมี "ปลุกพลัง": ชาร์จ → ระเบิดแสงทอง + สายฟ้า → ประทับดาวทีละดวง (hatchView `awaken()`) ยิ่งหายากยิ่งยาว/สายฟ้ามาก · **มหากาพย์ขึ้นไปมีฉากก่อนแตก** (`epicPre()`): เสา 4 ต้นรวมพลังหมุนวน → ยิงลำพลังใส่ไข่ → ไข่ลุกด้วยออร่าพลังแบบอนิเมะ + สายฟ้ารอบไข่ + ลำแสงพุ่งขึ้น + ร้าวทีละขั้น → ขาววาบ → ตูม (โค้ดวาดเอง ถ้ามีภาพ BATCH12 จะใช้ภาพแทน)
- **ฟักหลายฟอง ×5 / ×10 (เจ้าของขอ 2026-10-14):** หน้าฟักไข่มีปุ่ม "ฟัก ×5" (ไข่พร้อมฟัก ≥2 ฟอง) และ "ฟัก ×10" (≥6) — ฟักเท่าที่มีถ้าไม่ครบ · ผลบันทึกก่อนเริ่มฉาก (`startMultiHatch` ใน main.ts เรียก `hatchEgg` ทุกฟองแล้ว save) · ฉาก `render/multiHatchView.ts`: ไข่เรียงเป็นตาราง (จอกว้าง 5 ต่อแถว มือถือ 3 ต่อแถว ซูมให้พอดีจอ) แตกทีละฟอง เวลาสั่น/พักยาวขึ้นตามความหายาก · เอฟเฟ็คตามระดับ: ธรรมดา = ฝุ่นแสงเล็ก · หายาก = วงแหวนฟ้า + วาบ · มหากาพย์ = เสาแสงม่วง + สั่นจอ + ป้าย "มหากาพย์!" · ตำนาน = วาบทอง + สายฟ้า 4 สาย + รัศมีหมุน + ป้าย "ตำนาน!" · ร่างหายาก = วงแหวน 6 สีรุ้ง + ป้าย "ร่างหายาก!" · มอนหายากขึ้นไปมี **กรอบออร่า** รอบช่องหลังเผยตัว (สีตามระดับ เต้นเป็นจังหวะ ตำนานมีกรอบซ้อน ร่างหายากเป็นรุ้งไล่สี) · ตัวใหม่มีป้าย NEW! · แตะจอ = เร่ง (แตกเลย/ข้ามช่วงพัก) · ปุ่ม "ข้าม" = เผยที่เหลือทั้งหมด · จบแล้วหน้าสรุป (`multiSummary`): การ์ด 10 ใบพร้อมกรอบออร่า CSS (หายาก = เรืองฟ้า · มหากาพย์ = เรืองม่วงเต้น · ตำนาน = ขอบทองหมุน · ร่างหายาก = ขอบรุ้งหมุน) + สรุปจำนวน + ปุ่มฟักต่อ ×5/×10 · ฟักเดี่ยวยังเป็นฉากแท่นเต็มแบบเดิม
- **ไข่ป่า** (ฟาร์ม): อัปถูกกว่า + มี trait เฉพาะ · **ไข่ดารา** (กาชา Starborn): สีพิเศษ + สกิลต่าง พลังสูงสุดเท่ากัน
