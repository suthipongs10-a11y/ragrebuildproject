# CLAUDE.md — Project Eggbound (ไข่พันธสัญญา)

อ่านไฟล์นี้ก่อนทำงานทุกครั้ง แล้วอ่าน `docs/GAME_BLUEPRINT_v2_TH.md` เมื่อแตะระบบเกม

## 1. โปรเจกต์คืออะไร
เกมเก็บไข่-ฟักมอน แนวเทิร์นเบสสไตล์ Summoners War + ระบบจาก Ragnarok Online
- ไม่มีเดินในแมพ: แผนที่ภพ → แตะด่าน → สู้ 4v4 ทันที
- จุดขาย: ท่าทาง สกิล เอฟเฟ็คสวยอลังการ + **ปฏิกิริยาธาตุ** + ธีมตำนานรวม (ไทย + ตะวันตก + จีน/ญี่ปุ่น/กรีก/นอร์ส + เผ่าแปลก) ไม่ไทยจ๋า
- ออนไลน์แบบ async สไตล์ SW: เล่นคนเดียว เจอกันเฉพาะ PvP/อารีน่า/กิลด์วอ (WoE)/บอส MVP — **ทำ solo ให้ลงตัวก่อน**
- ภาษา UI/การคุยกับเจ้าของ: ไทย · ตอบสั้น ตรง แนะนำชัดเจน คุมต้นทุน

## 2. แบ่งงาน
- **Claude:** เขียนเกมทั้งหมด + VFX/ออร่า/ฟักไข่ด้วยโค้ด + เขียนไฟล์คำสั่งวาดภาพ (.txt) ให้ ChatGPT
- **ChatGPT:** วาดภาพทั้งหมดตาม `art/prompts/*.txt` เจ้าของเป็นคนส่งต่อ แล้วส่ง zip กลับมา
- ภาพใหม่: ตรวจครบ/ชื่อไฟล์/โปร่งใส/ไฟล์เสีย(truncated) → `python3 -I game/tools/import_art.py <set_dir> <ID> <ความสูงpx> [--mirror pose,pose] [--key monXXe]` → ตั้ง `art:` ใน `SPECIES`
  - **ภาพจาก Google Flow:** ได้ JPG สัดส่วนตายตัว (1:1, 9:16, 16:9) ชื่อไฟล์สุ่ม → จับคู่ชื่อเอง แล้ว `python3 -I game/tools/fit_flow.py <in> <out.png> <W>x<H> pad|crop|squash|anchor [--bottom F] [--key] [--anchor CX,CY,RX]` ปรับให้ตรง canvas ในไฟล์คำสั่งก่อนนำเข้า (ฐานยืน BATCH16: วัดจุดกลาง+ครึ่งความกว้างผิวบนของฐานในภาพ แล้วใช้ `1024x512 anchor --key --anchor CX,CY,RX` ย้ายไปจุดมาตรฐาน `PED` 512,150,380 → `import_fx.py`) (`--key` = ลบพื้นชมพู #FF00FF ของภาพวัตถุ/ตัวละคร + กันขอบชมพู · ตัดเฉพาะพื้นชมพูที่ต่อจากขอบภาพ สีม่วง/ชมพูในตัววัตถุจึงไม่หาย) · Flow วาดขนาดตัวไม่คงที่ทุกท่า → เทียบกับ idle แล้วย่อท่าที่ใหญ่เกินรอบจุดเท้า · Flow มักแถมภาพอ้างอิงที่แนบไป (เช่น fx_burst/fx_rays) ห้ามนำเข้าทับ
  - ภาพของมอนที่ยังไม่มีในเกม → `import_art.py ... --out assets_staged` (ไม่ฝังใน build จนกว่าจะย้ายเข้า `assets/`)
  - **เช็กทิศก่อนใช้ `--mirror`:** ท่าหน้าต้องหันขวาล่างแบบจิ้งจอก (หัวอยู่ขวา หางอยู่ซ้าย) — B05 เคยถูกกลับด้านผิดจนหันซ้าย (แก้แล้ว) · ส่งซ่อมบางท่า: เอาชุดเดิม + ภาพใหม่มารวมแล้วรันซ้ำความสูงเดิม (วัดจาก front_idle ในเกม) ภาพขนาดต่างกัน (1254 vs 1024) ย่อให้เท่ากันก่อน
  - ตัวนำเข้ายึด "เท้าจริง" ของแต่ละภาพ (ChatGPT ไม่วางเท้าที่ y=870 ตามสั่ง) · ความสูง: ตัวเล็ก 270 / ปกติ 300–320 / ตัวใหญ่-มหากาพย์ 360 · ภาพเสียจะข้ามและเกมใช้ท่าสำรอง (`spr()` → idle มุมเดียวกัน → master)

## 3. การตัดสินใจที่ล็อกแล้ว (ห้ามเปลี่ยนเองโดยไม่ถาม)
- เทิร์นเบส ATB · 3 สกิล + สกิลผู้นำ · ตัวแรกในทีม = ผู้นำ
- ภาพ 2D key pose (5 ท่า × 2 มุม: front/back) + แอนิเมชันด้วยโค้ด · 4 ทิศได้จาก mirror · **ไม่ทำ frame-by-frame**
- **ยกระดับการเคลื่อนไหวให้ใกล้ SW (ตัดสินใจ 2026-10-12, ทำตัวต้นแบบจิ้งจอกก่อน):** ท่าเพิ่ม windup/strike/follow (โจมตี 3 จังหวะ), cast2, joy, down (BATCH13-A) — ท่าที่ไม่มีจะใช้ท่าเดิมแทน (`poseKey()`) · "ภาพมีชีวิต" ด้วยโค้ด `warpDraw()` (หายใจ/โน้มตัว/สปริงตามแรง/ระลอก) · ท่าสกิลเฉพาะตัว = เมธอด `sk_<skillId>` ใน battleView (ไม่มีจะใช้ท่ากลาง) · ตัวเลขดาเมจแบบ SW `dmgText()` · ประกายโดนตี `hitSpark()` · ผ่านต้นแบบแล้วค่อยทำตัวอื่น
- ออร่าดาว, VFX, ฟักไข่ = โค้ดล้วน ใช้ได้กับทุกตัว
- **สีตามดาว:** ★4 เปลี่ยนสี/★5 ร่างวิวัฒน์ แสดงเฉพาะตอนอัปดาวเกินดาวที่เกิดมา (`lookOf` เทียบ `natStars`) — ตัวตำนานเกิด ★4 ยังเห็นสีจริง
- **ดาวแบบ SW (ตัดสินใจ 2026-10-12):** ฟักออกมาดาวตามความหายาก ธรรมดา ★1 · หายาก ★2 · **มหากาพย์ ★4 · ตำนาน ★5 (เปลี่ยน 2026-10-13)** · **ร่างหายาก +1 ดาว** (`natStars(sid, rare)`) · โอกาสร่างหายากลดตามระดับ `RARE_FORM_MULT` ธรรมดา ×1 · หายาก ×0.8 · มหากาพย์ ×0.5 · ตำนาน ×0.25 (ตำนานร่างหายาก ★6 ≈ 1 ใน 30,000 ไข่ดรอป) · อัปได้ถึง ★6 ทุกตัว · ฟักได้สายพันธุ์ใหม่ครั้งแรก → ตราประทับ "NEW!" สีรุ้งมุมบนซ้าย (`newBadge()`) (ไข่ซ้ำ +1 ดาว) · ค่าใน `NAT_STARS`/`MAX_STARS` (data.ts) · ฉากฟักตัวหายากขึ้นไปมี "ปลุกพลัง": ชาร์จ → ระเบิดแสงทอง + สายฟ้า → ประทับดาวทีละดวง (hatchView `awaken()`) ยิ่งหายากยิ่งยาว/สายฟ้ามาก · **มหากาพย์ขึ้นไปมีฉากก่อนแตก** (`epicPre()`): เสา 4 ต้นรวมพลังหมุนวน → ยิงลำพลังใส่ไข่ → ไข่ลุกด้วยออร่าพลังแบบอนิเมะ + สายฟ้ารอบไข่ + ลำแสงพุ่งขึ้น + ร้าวทีละขั้น → ขาววาบ → ตูม (โค้ดวาดเอง ถ้ามีภาพ BATCH12 จะใช้ภาพแทน)
- **ไข่ป่า** (ฟาร์ม): อัปถูกกว่า + มี trait เฉพาะ · **ไข่ดารา** (กาชา Starborn): สีพิเศษ + สกิลต่าง พลังสูงสุดเท่ากัน
- **กาชาเน้นอุปกรณ์มอน** (4 ช่อง + เซ็ต) ไม่ใช่ขายตัวมอน
- **ร่างหายาก (ตัดสินใจ 2026-10-12, แทน "พลังหลักเท่าเดิม"):** ค่าพลังเท่าร่างปกติ แต่ได้ **สกิลที่ 4 = พาสซีฟเฉพาะสายพันธุ์** (`rarePassive` ใน data.ts แก้เป็นข้อมูลได้) + สีตัวเฉพาะ (แสง/มืด ดูข้อถัดไป) + ออร่ารุ้งทุกฉาก + ท่าไม้ตายเวอร์ชันทอง/รุ้ง · สารบัญแสดงพาสซีฟนี้ให้เห็นตลอด (เปลี่ยน 2026-10-14 ดูข้อ "ขั้นของมอน") · พาสซีฟต้อง deterministic และผ่าน `tests/passives.ts` (ทีมร่างหายากล้วนชนะเพิ่มได้ไม่เกิน ~10%) · ลอกกลไกจากเกมอื่นได้ แต่ชื่อ/ดีไซน์ต้องของเราเอง
- **ร่างหายาก = มอนแสง/มืดอีกตัว (ตัดสินใจ 2026-10-13 แทนแบบสีเดียว):** ชื่อเดิม ธาตุเปลี่ยนเป็นแสงหรือมืด (`rareForm` ใน `RARE_FORMS` data.ts · ตัวแสงเดิม→มืด ตัวมืดเดิม→แสง ที่เหลือตามธีม: แสง 13 มืด 11) · สกิล 1 ท่าเดิมเปลี่ยนธาตุ (`formOf()` ย้ายเครื่องหมาย/คำบรรยาย) · **สกิล 2–3 ของตัวเอง** ใช้กลไกประจำธาตุ — แสง: ชุบชีวิต อมตะ ภูมิคุ้มกัน ปกป้อง คูลดาวน์ทีม −1 (ไม่ลดท่าไม้ตาย) ไม่สนใจ DEF · มืด: ลบบัฟ ยั่วยุ ผนึกสกิล ห้ามฮีล ตราบาป (+25%) ระเบิดเงา (2 เทิร์นระเบิด+มึน) ขโมยเกจ · พาสซีฟร่างหายาก/ค่าพลัง/สกิลผู้นำเท่าเดิม · **ร่างแสง/มืดเป็น "ไวลด์":** ตีโดนเครื่องหมายธาตุอื่น หรือเครื่องหมายแสง/มืดที่มันติดไว้โดนธาตุอื่นตี = สุริยคราสเบา (0.6 แทน 0.9) ทีมเดิมยังจุดปฏิกิริยาได้ · สารบัญ 1 ช่องต่อสายพันธุ์ ร่างหายากเป็นปุ่มในช่องเดียวกัน แต่นับเป็นอีกร่าง (`dexRare`) · สีตัว `elemTint()`: แสง = ขาวมุก (เงาลาเวนเดอร์ ไฮไลต์ครีม ประกายมุก) มืด = ม่วงลึกลับ ทั้งคู่คงขอบทอง (เจ้าของเลือก: แสงไม่ขาวจัด มืดเป็นม่วงไม่ใช่คราม) · test ใน `tests/passives.ts` · สมดุล: สลับร่างหายากเข้าทีมเดิม 1 ตัว ส่วนมาก ±10% (สไลม์ร่างแสงในทีมเริ่มต้น −20% เพราะทีมนั้นพึ่งไอน้ำ/พายุจากเครื่องหมายเปียก — ร่างปกติกับร่างหายากเหมาะคนละทีม) · ทีมร่างหายากล้วน +17–22% (เกินเกณฑ์ 10% เดิม รอเจ้าของตัดสิน)
- **ขั้นของมอน 4 ขั้น (เจ้าของเลือกตามที่แนะนำ 2026-10-14 — กันระบบมั่ว/คุมจำนวนภาพ):** ① ร่างปกติ (ธาตุเดิม, ภาพหลัก) ② ร่างหายาก แสง/มืด (ชื่อเดิม ภาพเดิมย้อมสี สุ่มจากไข่ — ตามเดิม) ③ ร่างวิวัฒน์ ★5 = **ภาพใหม่ 1 ชุดต่อสายพันธุ์** ร่างหายากใช้ภาพเดียวกันย้อมสี (ไม่ทำร่างวิวัฒน์แยกทุกธาตุ) ④ **ตัวพิเศษ** = เฉพาะตัวเด่นไม่กี่ตัว (ราวภพละ 1–2) ชื่อใหม่ ภาพใหม่ของตัวเอง ดาวสูงกว่า เก่งกว่า ได้จากไข่พิเศษเท่านั้น · **ตัวพิเศษไม่ผูกกับธาตุแสง** ผูกกับเรื่องราวของตัวนั้น (ไม่ทำให้ธาตุแสงเหนือกว่าทั้งระบบ — ร่างมืด 11 ตัวจะด้อยทันที) · ตัวแรก = ขุนสมิงเผือก (BATCH19B) · ไข่พิเศษ/ตัวเลขพลังยังไม่ตัดสิน (ที่แนะนำ: ไข่ชนิดใหม่ดรอปยาก/ประกอบจากเศษ · +1 ดาวเกิด + ค่าพลัง +10%)
- **สารบัญมอนแบบรวมช่อง (เจ้าของขอ 2026-10-14, ทำแล้ว):** `dexHTML()` ใน main.ts — 1 ช่องต่อสายพันธุ์ (`dexFams`) มีปุ่มเลือกร่าง/ธาตุ (`.ftab`: ร่างปกติ · ร่างหายาก · ตัวพิเศษในอนาคต) แต่ละร่างข้อมูลของตัวเอง · **ไม่ซ่อนอะไร** (ภาพ สกิล พาสซีฟร่างหายาก เห็นหมด) ร่างที่ยังไม่ได้แค่ภาพหม่นลงนิด · การ์ดบอก ได้แล้ว/ทั้งหมด (`1/2`) + จุดธาตุของแต่ละร่าง (จุดจาง = ยังไม่มี) · กรองธาตุแล้วการ์ดเปิดร่างธาตุนั้นให้ · แต่ละร่างมีกล่อง "หาได้จาก" (`dexSources`): โอกาสต่อฟองของไข่ปริศนาแต่ละลาย (สัดส่วนระดับความหายาก ÷ จำนวนสายพันธุ์ระดับนั้น × โอกาสร่างหายาก) · ไข่ระบุชื่อ + โซนที่ดรอปเศษ · ตำนานดารา = บอสโซน/เศษ 40 ชิ้น · นับรวม 52 ร่าง 28 สายพันธุ์
- **เพชร (ตัดสินใจ 2026-10-12):** ทองใช้เหมือนเดิม · เพชรใช้ได้แค่ซื้อไข่ปริศนาลายทอง + เร่งเวลาบ่มไข่ + เติมพลังงาน AUTO (วันละ 3 ครั้ง, 2026-10-13) (เพิ่มการใช้งานอื่นต้องถามก่อน) · **ราคาเร่งเป็นขั้นบันไดต่อวัน (2026-10-13, กันสายเติมปั๊ม):** ไข่ทอง 10 · 12 · 14 · 16 · 20 · 24 · 30 · 36 · 45 · 55 · 70 · 85 · 100 (เพดาน) ไข่รุ้ง ×3 (30 → 300) นับรวมทุกการเร่งของวัน รีเซ็ตเที่ยงคืนเวลาเครื่อง · ไข่ที่บ่มไปแล้วจ่ายตามสัดส่วนเวลาที่เหลือ (อย่างน้อย 1) · ค่าอยู่ที่ `RUSH_BASE`/`RUSH_STEP` (data.ts) · test ล็อกบันไดใน `tests/eggs.ts` · ได้เพชรจากสมุดผจญภัย (ภารกิจครั้งเดียว, **รวม 800 เพชร** ตามเนื้อหาปัจจุบัน: 600 + แผนที่ 2–3 แผนที่ละ 100 = โซนละ 10 + บท 40 — `tests/eggs.ts` ล็อกค่านี้) · **สมุดแบบ SW แบ่งเป็นบท** (`CHAPTERS` ใน quests.ts): มือใหม่ · หนึ่งบทต่อแผนที่ (ทุกโซนมี ชนะบอส/3 ดาวทุกด่าน/ชนะบอส 5 ครั้ง สร้างอัตโนมัติจาก `ZONES`) · ฟักไข่/สะสม · เติบโต/วิวัฒน์ (ถึง ★5 ร่างวิวัฒน์, ★6) · จอมยุทธ์ · บ้านเต่า — ทำครบบทเปิดหีบรางวัลบท · แผนที่ใหม่เพิ่มเพชรได้ทีละบท (ต้องถามก่อนถ้าเกิน) · อนาคตขายเป็นแพ็กเกจ

- **พลังงาน (Energy) ใช้กับ AUTO เท่านั้น (เจ้าของตัดสิน 2026-10-13):** เล่นเองไม่จำกัด · เปิด AUTO จ่ายพลังงานเท่า `stamina` ของด่าน (3–12) ครั้งเดียวต่อการต่อสู้ (เปิด/ปิดซ้ำในด่านเดิมฟรี) · ไม่พอ = เริ่มแบบเล่นเองพร้อมแจ้งเตือน · เต็ม `ENERGY_MAX` 60 ฟื้น 1 แต้มทุก 5 นาที (`ENERGY_REGEN_MS`, ฟื้นตอนปิดเกมด้วย) · โค้ด `game/energy.ts` (เซฟ `energy: {v, t}`) · แสดงในแถบบน ⚡ พร้อมเวลานับถอยหลัง (มือถือซ่อนเวลา) · **เติมด้วยเพชรได้ (เจ้าของอนุมัติ 2026-10-13):** ครั้งละ +60 (`ENERGY_REFILL_GEMS` 30 เพชร) วันละ `ENERGY_REFILL_DAILY` 3 ครั้ง รีเซ็ตเที่ยงคืนเวลาเครื่อง (เซฟ `enBuy: {day, n}`) เติมเกินหลอดได้ (เกินเพดานแล้วไม่ฟื้นเพิ่ม) · แตะ ⚡ แถบบน หรือกด AUTO ตอนพลังงานไม่พอ = แผ่นเติม (`enModal()` ใน main.ts) ซื้อจากปุ่ม AUTO แล้วเปิด AUTO ให้ทันที · test ใน `tests/eggs.ts` · ฟาร์มบอสดาราใช้พลังงานตามปกติ (เจ้าของ: ดรอปยากอยู่แล้ว ไม่ต้องลดราคา)
- **บอสตำนานดารา + เศษไข่ดารา (เจ้าของเลือก 2026-10-13):** ตำนานดาราบางตัวเป็นบอสโซนที่เข้าธีม · ชนะครั้งแรกได้เศษไข่ดารา 1 ชิ้น หลังจากนั้น **5% ต่อรอบ** ครบ **40 ชิ้น** ประกอบเป็นไข่ (`STAR_SHARD_CHANCE`/`STAR_SHARDS_TO_CRAFT`, เฉลี่ย ~800 รอบ — ตั้งใจให้ฟาร์มนาน) · ตำนานดาราไม่ออกจากไข่ปริศนา ไม่มีร่างหายาก · ค่าพลังระดับตำนาน (★5 เกิด) · ภาพเป็นไฟล์แยก `assets_ext/` (โหลดตอนจะใช้)
- **ชุดพิเศษ "ตำนานดารา" (Starborn Legends, ตัดสินใจ 2026-10-12):** ได้จาก ① สุ่มไข่ดารา ② แต้มสะสมแลกตัวที่ต้องการ ③ **ดันฟาร์มชิ้นส่วนไข่ดาราที่เปิดเป็นช่วงๆ** (ประกอบเป็นไข่) — ผู้เล่นฟรีได้ แค่ช้ากว่า · พลังสูงสุดเท่ามอนอื่น เด่นที่ดีไซน์/ท่าไม้ตาย/ฉากฟัก (ข้อยกเว้นของ "กาชาเน้นอุปกรณ์")
- **ตำนาน (ตัดสินใจ 2026-10-13):** ท่าไม้ตายตำนานเป็นฉากใหญ่ `legendFx()` (น้ำ = คลื่นยักษ์ 3 ลูกซัดข้ามสนาม + งูน้ำผุด, ธาตุอื่นมีชุดของตัวเอง) · **ตำนานร่างหายาก ★6 = "ร่างตำนานลึกลับ" (mythic):** ท่าไม้ตาย ×1.2 พลัง และคูลดาวน์ −1 (`MYTHIC_ULT` ใน data.ts, test ใน passives.ts) + ฉากท้องฟ้าดาว/วงอักขระทอง/ป้าย ✦ · ฉากฟัก: ดาวดวงที่ 6 เป็นสีรุ้ง + สายฟ้าฟาด
- **ฐานยืน + ออร่าตามความหายาก (ตัดสินใจ 2026-10-13):** เวทีโชว์มอนยืนบนฐานตามธาตุ 6 แบบ (`render/pedestal.ts`: ใช้ภาพ `ped_<ธาตุ>` จาก BATCH16 ถ้ามี ไม่งั้นวาดฐานหิน/หินอ่อนด้วยโค้ด) · ออร่าซ้อนเป็นชั้นตามลำดับความหายาก (`render/showcase.ts`): ธรรมดา = แสงธาตุ · หายาก = อัญมณี/วงแหวนฟ้า + คลื่นแสงแผ่บนฐาน + ประกาย · มหากาพย์ = วงอักขระม่วงหมุนใต้เท้า + เปลวออร่าหลังตัว · ตำนาน = ทองทั้งชุด (วงอักขระ/ขอบฐาน/รัศมี/เปลวชั้นที่สอง/ลำแสงลอยขึ้นจากขอบฐาน) · ร่างวิวัฒน์ (★5 ขึ้นไปที่อัปเกินดาวเกิด) = เสาแสง + ลูกแก้ว 3 ลูกโคจรรอบตัว + ขอบฐานทอง + ชิป "ร่างวิวัฒน์" · ร่างหายาก = ทุกอย่างเป็นสีรุ้ง + วงรัศมีหลังตัว · ตำนานร่างหายาก = + ท้องฟ้าดาว · ทุกดาวแรงขึ้นนิด ★6 ออร่าทอง · ภาพฐานห้ามมีแสงฟุ้ง/ประกาย (เกมวาดออร่าเอง)
- **ท่าไม้ตายต้องอลังการ:** ซูมกล้องเข้าหาตัวมอน ทำท่า burst + speed lines แล้วสกิลระเบิดเต็มจอ (ภาพเอฟเฟ็ค BATCH09 ย้อมสีตามธาตุ)
- **หน้าคลังมอนแบบ SW (ตัดสินใจ 2026-10-13):** ซ้าย = เวทีโชว์มอนเต็มตัวท่า idle ขยับได้ (`render/showcase.ts`, แคนวาส `#mshow`, แตะ = โชว์ท่า) + แท็บ ข้อมูล/⬆ เลเวล/★ อัปดาว/✦ สกิล · ขวา = คลังมอนเลื่อนในตัวเอง แสดงตลอด (มือถือ: อยู่ใต้เวที; ชื่อ/ดาว/เลเวลเป็นแถบใต้เวที) · แท็บเลเวล/ดาว/สกิล แตะมอนในคลัง = เลือกเป็นอาหาร (ช่องอาหารแตะเพื่อเอาออก) · "เลือกอัตโนมัติ" ไม่หยิบมอนในทีม ร่างหายาก ตัวสุดท้ายของชนิด และเลี่ยงตัวชนิดเดียวกัน · มอนในทีมใช้เป็นอาหารไม่ได้
- P0 ใช้ **Canvas 2D** แทน PixiJS (พิสูจน์แล้วว่าเอฟเฟ็คพอ) — ย้ายไป PixiJS ได้ถ้าวัด fps แล้วไม่พอ

### ฉากเข้าต่อสู้ (สไตล์ของเรา ตัดสินใจแล้ว)
- เริ่มด่าน: ทีมเราเดินเข้าฉากจากด้านหลังกล้อง แล้วศัตรูตกลงมาจากด้านบน (ต่างจาก SW ที่ศัตรูยืนรอ)

- โค้ด: `walkIn / walkOut / march` ใน battleView.ts
### บ้าน (Home) = เต่าบรรพกาลแบกเกาะ (ตัดสินใจแล้ว)
- ไม่ใช้เกาะลอยฟ้า (เหมือน SW เกินไป) → บ้านอยู่บนหลังเต่ายักษ์ว่ายในทะเลเมฆ (ตำนานเต่าแบกเกาะเผิงไหล/กูรมะ)
- เลเวลป้อมพันธสัญญา = เต่าโตขึ้น 4 ขั้น + ปลดล็อกอาคาร + เพดานเลเวลอาคารอื่น

- วัตถุศักดิ์สิทธิ์ = สกิลติดตัวทีม เลือกพกได้ 1 ชิ้น/ทีม (ตราสุริยัน, ขนนกวายุ, เกล็ดกระดอง, น้ำเต้าอมฤต)

## 4. กฎลิขสิทธิ์ (บังคับ)
1. ใช้ได้เฉพาะตำนาน/นิทาน/ศาสนา/วรรณกรรมหมดลิขสิทธิ์ (ไซอิ๋ว ห้องสิน ซานไห่จิง รามเกียรติ์ กรีก นอร์ส อียิปต์ โยไค)
2. **ห้าม** ตัวละคร ชื่อ ชุดสกิล ดีไซน์ จาก Dota 2, LoL, SW, หนัง, นิยายสมัยใหม่ · ห้ามชื่อคนจริง
3. บอสที่ได้แรงบันดาลใจจากเกมอื่น ต้องต่างทั้งชื่อ หน้าตา สีหลัก อาวุธ กลไก
4. ทุกคำสั่งวาดภาพต้องมี "original design, do not copy any existing game/film character"
5. **ห้ามเอาสัตว์ประหลาดจากหนัง (เช่น ก็อตซิลล่า/ไคจูของ Toho) มาเปลี่ยนชื่อใช้** — แนว "สัตว์ยักษ์" ทำได้ แต่ต้องมาจากตำนานหมดลิขสิทธิ์ (ยามาตะโนะโอโรจิ, ไฮดรา, เลวีอาธาน, คิเมร่า, วาลคิรี, นาค 5 เศียร) และออกแบบเองทั้งหมด
6. **ยืม "แนว/บรรยากาศ" จากการ์ตูนดังได้ แต่ห้ามลอกของเฉพาะ** (เช่น เซนต์เซย่า: ชุดเกราะในตำนานเงาวับ ธีมกลุ่มดาว = ได้ · ดีไซน์ชุดเกราะ/ตัวละคร คำเฉพาะ Saint/Cloth/Cosmo ท่าไม้ตายเฉพาะ และโครง 12 อัศวินทองจักรราศี = ห้าม) · ตั้งชื่อเองได้ เช่น ซามูไรครอส

## 5. โครงโค้ด (`game/`)
```
src/core/      battle-core: TypeScript ล้วน ไม่แตะ DOM — types, rng (mulberry32), data (SPECIES/STAGES/สูตรค่า), battle
src/render/    engine (canvas, particles, coroutine scripts), battleView, hatchView (แท่นฟักไข่), chestView (หีบสมบัติจบด่าน), homeView, assets (sprites/recolor/anchors/portrait), audio (WebAudio synth)
src/game/      save (localStorage, v1), progression (รางวัล/เลเวล/เศษไข่/ไข่ปริศนา/ฟัก), home (บ้านเต่า + ช่องบ่มไข่)
src/main.ts    app shell: หน้าจอ DOM, input, loop
src/index.template.html  CSS + โครง HUD (มี /*ASSETS*/ และ /*BUNDLE*/ ให้ build แทนที่)
assets/        sprite 512px webp — pivot เท้า (256,435) · ไข่ ฐานที่ y≈425
tools/import_art.py      แปลงชุดภาพ ChatGPT (1024px, เท้า y=870) → assets/
tests/sim.ts   ตรวจ determinism + จำลองสมดุลหลายร้อยรอบ · tests/eggs.ts ตรวจระบบไข่ (การันตี/บ่ม/ดาว/migrate เซฟ)
```
กฎสถาปัตยกรรม:
- **Battle core deterministic:** seed เดียว + คำสั่งเดียว = ผลเดียว · AI ใช้ RNG แยกต่อทีม (`aiRng`) คำสั่งผู้เล่นจะได้ไม่ทำให้ลูกเต๋าต่อสู้เลื่อน · core ส่ง `ActionResult` + event log ให้ renderer เล่น — renderer ห้ามคำนวณผลเอง (เตรียมให้เซิร์ฟเวอร์ replay ตรวจโกงใน P2)
- ค่าสมดุลอยู่ใน `data.ts` / config ไม่ฝังใน renderer (ไข่: `EGG_TIERS`, `EGG_DROP`, `NAMED_RARE_FORM` ใน data.ts · `HATCH_SPEED` ใน home.ts · สีหีบสมบัติ: `LOOT_GRADES`, `EGG_LOOT_GRADE` ใน data.ts — การ์ดมอน (M4) ให้เกรด legendary)
- ทุกการแก้ core ต้องรัน `npm test` ให้ผ่าน determinism

## 9. ข้อควรระวังที่เคยเจอ
- เดิมฝังภาพทั้งหมดเป็น data URI ใน HTML เดียว (เพดาน 16MB) · ภาพมอนแบบไฟล์แยก (`assets_ext/`) โหลดด้วย `<img>` ธรรมดาก่อน (แบบเดียวกับภาพฉาก) ถ้าแคนวาสอ่านพิกเซลไม่ได้ค่อยลอง `<img crossOrigin>` แล้ว fetch → blob (`loadExt()` ใน assets.ts) — **Artifact จริงไม่ยอมให้ fetch ไฟล์พวกนี้ (2026-10-14 ตำนานดาราเลยเป็นจิ้งจอก)** ทดสอบด้วยเซิร์ฟเวอร์ที่ปฏิเสธ fetch (`srv2.mjs nofetch` ใน scratchpad) · หน้าตั้งค่ามีบรรทัด "ภาพไฟล์แยก" บอกจำนวนที่โหลดได้/วิธีโหลด/ข้อผิดพลาด (`EXT_STAT`, `plateStat()`) ไว้ให้เจ้าของเช็กในเครื่องจริง · ก่อนสู้/ฟักต้อง `ensureArt()` · แคชภาพที่ทำไว้ก่อนภาพมาถูกล้างด้วย `forgetArt()` · ภาพฉาก BATCH17 เผยแพร่เป็นไฟล์แยกผ่าน `files` ของ Artifact (`bg/<loc>.webp` ข้าง index.html) — โหลดไม่ได้ = ใช้ฉากโค้ดแทนเงียบๆ · canvas หลักอาจโดน taint จากภาพแยก → ห้ามอ่านค่าพิกเซล/`toDataURL` จาก `E.cv` หรือ `E.ground`
- ฟอนต์ Google อาจโหลดไม่ได้ในบางที่ → มี timeout ไม่ให้เกมค้าง
- localStorage ใช้ไม่ได้บางบริบท → ทุกการอ่าน/เขียนครอบ try/catch แล้ว
- `#loading{display:grid}` ทับ attribute `hidden` → ต้องมี `[hidden]{display:none!important}` ใน template (นอก Artifact หน้าโหลดค้าง)
- mkUnit ต้องตั้ง max = hp จริง (เคยทำฮีลเพี้ยน)
- ท่าใหม่ (BATCH13 windup/down/joy ...) ไม่มีในตารางจุดยึดมือทำของจิ้งจอก (`ANCH`) → `anchOf` ต้องถอยไปใช้ท่าหลัก (เคยค้างทั้งเกมตอนจิ้งจอกร่างปกติตายระหว่าง Auto) · ลูปเฟรม `frame()` ครอบ `guard()` และสคริปต์ coroutine ที่ error ถูกตัดทิ้งแยกตัว — error ใหม่จะขึ้น toast ครั้งเดียว ไม่ทำให้เกมหยุด
- `HatchView` constructor ต้อง `Object.assign(this, opts)` ก่อนใช้ค่าใดๆ — เคยเผลอทำให้บรรทัดนี้กลายเป็นคอมเมนต์ (2026-10-13) ไข่ปริศนาทุกลายเลยแสดงเป็นไข่ของมอนที่สุ่มได้ (เผยผลก่อนฟัก) และดาว/ร่างหายาก/ระดับฉากฟักผิดหมด · ทดสอบ: ฟักไข่ทุกลายแล้วดูว่าไข่บนแท่นเป็นลายปริศนา
